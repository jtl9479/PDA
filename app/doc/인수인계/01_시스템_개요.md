> 인수인계 문서 01/09 · 작성일 2026-10-22

## 1. 이 시스템은 무엇인가

(주)하이랜드이노베이션 물류센터에서 **마트 출하 박스를 계근하는 Android PDA 앱**이다.

1. 서버(ERP)에서 그날 출하할 대상(마트·센터·품목·수량)을 PDA로 받는다.
2. 박스 바코드를 스캔하면 바코드에서 중량·제조일자를 읽어 출하 대상과 맞춘다.
3. 마트별 물류 라벨을 블루투스 라벨 프린터로 출력한다.
4. 계근 결과를 서버로 보내 ERP 출고계근 테이블에 저장한다.

이마트·홈플러스·롯데·도매업체와 비정량(이마트·홈플러스) 출하를 한 앱에서 처리한다.

## 2. 프로젝트 목적과 원칙

### 2.1 원칙
**기존 기능과 100% 동일하게 동작해야 한다.** 기능은 그대로 두고 장비와 DB만 바꾸는 전환 프로젝트다.
회사코드와 하드코딩(창고코드 등)만 예외로 바꿀 수 있다.

### 2.2 목적
| # | 목적 | 내용 |
|:-:|------|------|
| 1 | 장비 전환 | PDA는 Honeywell, 프린터는 BIXOLON으로 교체 |
| 2 | DB 전환 | Oracle → MSSQL. ERP 프로그램 변경에 따라 테이블·컬럼도 변경 |
| 3 | 하드코딩 변경 | 창고코드 등 고정값을 ERP 조회로 변경 |
| 4 | 소스 정리 | 큰 Activity를 역할별 클래스로 분리, 미사용 소스 삭제 |
| 5 | 회사코드 추가 | 회사코드 `20` 기준으로 조회·저장 |
| 6 | 기존 기능 유지 | 위 변경 외 동작은 원본과 동일 |

## 5. searchType별 마트 구분

메인 화면의 [출하대상받기]를 누를 때 `Common.searchType`이 정해진다. [계근입력시작]은 받아 둔 타입과 같은지만 검사하고, 계근 화면은 이 값으로 처리 클래스(`shipment/mode/`)를 고른다(`ShipmentModeFactory`).

| searchType | 업무 | 출하대상 조회 JSP | 바코드정보 조회 JSP | 계근 전송 JSP | 처리 클래스 | 운영 |
|:-:|------|------|------|------|------|:-:|
| 0 | 이마트 출하 | `search_shipment.jsp` | `search_barcode_info.jsp` | `insert_goods_wet.jsp` | `EmartMode` | 사용 |
| 1 | 생산 계근 | `search_production.jsp` | `search_barcode_info.jsp` | `insert_goods_wet_production.jsp` | `ProductionMode` | **미사용** (버튼 숨김) |
| 2 | 홈플러스 하이퍼 출하 | `search_shipment_homeplus.jsp` | `search_barcode_info.jsp` | `insert_goods_wet_homeplus.jsp` | `HomeplusMode` | 사용 |
| 3 | 도매업체 출하 | `search_shipment_wholesale.jsp` | `search_barcode_info.jsp` | `insert_goods_wet_new.jsp` | `WholesaleMode` | 사용 |
| 4 | 비정량 출하 (이마트) | `search_production_nonfixed.jsp` | `search_barcode_info_nonfixed.jsp` | `insert_goods_wet_new.jsp` | `EmartNonfixedMode` | 사용 |
| 5 | 홈플러스 비정량 출하 | `search_homeplus_nonfixed.jsp` | `search_homeplus_nonfixed2.jsp` | `insert_goods_wet_new.jsp` | `HomeplusNonfixedMode` | 사용 |
| 6 | 롯데 출하 | `search_shipment_lotte.jsp` | `search_barcode_info.jsp` | `insert_goods_wet_lotte.jsp` | `LotteMode` | 사용 |
| 7 | 생산 라벨 | `search_production_4label.jsp` (서버에서 삭제됨) | `search_barcode_info.jsp` | `insert_goods_wet_production.jsp` | `ProductionLabelMode` | **미사용** (버튼 숨김) |

> - 1·7은 화면에서 숨기고(`visibility="gone"`) 코드는 보존했다. 정리하지 않기로 결정된 상태다.

## 6. 화면 구성

```
LoginActivity ── 사번·비밀번호 입력, 창고 선택
   │
   ▼
MainActivity ── 작업일자 선택, 마트별 [출하대상받기] / [계근입력시작]
   │
   ├─▶ BixolonShipmentActivity ── 계근 화면 (스캔 · 계근 저장 · 라벨 출력 · 전송)
   │      ├─ WetDetailDialog ───── 계근 상세 팝업 (재출력, 삭제, 합산 라벨)
   │      ├─ ExpiryEnterActivity ─ 소비기한 입력 (수기 중량 입력 시, 조건은 6.1)
   │      └─ DeviceListActivity ── 블루투스 프린터 선택 (저장된 프린터 주소가 없을 때)
   │
   ├─▶ ProductionActivity ── 생산 계근 계산
   └─▶ SettingActivity ───── 프린터 사용 ON/OFF (메뉴 [프린터설정])
```

### 6.1 화면별 역할

| 화면 | 역할 | 비고 |
|------|------|------|
| `LoginActivity` | 로그인, 창고 목록 조회·선택, 로컬 DB 테이블 생성, 프린터 설정값 읽기 | |
| `MainActivity` | 작업일자 선택, 출하대상 다운로드, 계근 화면 진입, [계근대상삭제], 종료 | 다운로드한 타입과 다른 [계근입력시작]을 누르거나 목록이 비어 있으면 막는다. [계근대상삭제]는 이름과 달리 로컬 출하대상(`TB_SHIPMENT`)만 지운다 |
| `BixolonShipmentActivity` | 바코드 스캔 → 출하대상 매칭 → 로컬 저장(박스 순번) → 라벨 출력 → 서버 전송 | 메뉴에 [테스트 출력] 있음 |

| `DeviceListActivity` | 페어링된 블루투스 프린터 목록에서 선택, [Scan for devices]로 새 기기 찾기 | 프린터 사용 ON이고 저장된 주소가 없으면 계근 화면 진입 시 뜬다. 취소하면 프린터 사용이 OFF로 저장된다 |

## 7. 한눈에 보는 업무 흐름

```
로그인(창고 선택)
  → 작업일자 선택
  → [출하대상받기]   searchType 결정, 받기 전에 로컬 데이터 정리 후 3단계로 받음
       ① 출하대상      → TB_SHIPMENT
       ② 바코드정보    → TB_BARCODE_INFO
       ③ 기존 계근분   → TB_GOODS_WET (서버 SM_출고계근에 이미 있는 계근, SAVE_TYPE='Y')
       → "바코드정보 없는 상품" 팝업
  → [계근입력시작]   받은 타입과 같은지 검사 후 BixolonShipmentActivity
  → 작업방식(바코드 / 수기(중량) / 상품코드) · 센터 선택
  → 첫 박스 스캔     품목 확인 → 작업지점 목록을 불러오고 계근이 끝나지 않은 첫 지점 자동 선택 (계근은 안 함)
  → 다음 스캔부터    선택 BL의 남은 행에 계근 → 중량·제조일자 추출 (첫 박스는 한 번 더 스캔 — 05 문서 2.3)
  → 로컬 저장        TB_GOODS_WET (박스 순번 부여, SAVE_TYPE='F' 미전송)
  → 라벨 출력        프린터 사용 ON일 때만. 출력한 라벨 값을 같은 행에 다시 저장
  → [전송]           미전송('F') 행 → 계근 전송 JSP → ERP SM_출고계근
```

> [출하대상받기] 전에 지우는 범위: `TB_SHIPMENT`·`TB_BARCODE_INFO` 전체, `TB_GOODS_WET`은 서버에서 받은 'Y' 행만. **아직 전송하지 않은 'F' 행은 남는다.**

마트별 상세 흐름은 `05_마트별_업무흐름`, 라벨 규격은 `07_라벨_규격`, 바코드 규칙은 `08_바코드_규칙`에 정리한다.
