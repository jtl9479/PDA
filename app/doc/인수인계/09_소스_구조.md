### 2.2 `shipment/` — 계근 화면에서 나눈 부분 (개발/76·77)

| 패키지 | 클래스 | 역할 |
|------|------|------|
| `mode/` | `ShipmentMode` (인터페이스) | 마트마다 다른 판단·계산·동작 19가지 (중복 확인, 소비기한, 중량 자릿수, 저장, 라벨, 전송 방식·주소 등) |
| | `ShipmentModeFactory` | searchType → 처리 클래스 생성 |
| | `EmartMode`(0), `EmartNonfixedMode`(4), `HomeplusMode`(2), `HomeplusNonfixedMode`(5), `WholesaleMode`(3), `LotteMode`(6), `ProductionMode`(1), `ProductionLabelMode`(7), `UnregisteredMode`(그 외) | 마트별 구현 |
| `scan/` | `ScanProcessor` | 스캔 바코드 처리 흐름 전체 (품목 확인 → 지점 선택 → 검사 → 저장 호출) |
| | `ScanState` | 스캔 상태 값 (작업 품목, 현재 지점, 작업방식 등) |
| | `ScanHost` | `ScanProcessor`가 화면에 요청하는 기능 (화면이 구현) |
| | `BarcodeInfoFinder` | 박스 바코드 → 품목 찾기 (08 문서 3장) |
| | `BarcodeParser` | 중량·제조일자·박스시리얼 추출 (08 문서 4장) |
| `task/` | `ShipSelectTask` | 센터·품목의 출하대상(작업지점) 조회 |
| | `ShipmentSendTask` | 계근 전송 (건별·일괄) |
| | `PrintConnectTask`, `PrintDisconnectTask` | 프린터 연결·해제 |
| `dialog/` | `WetDetailDialog` | 계근 상세 팝업 (재출력·삭제·합산) |

> 나눈 클래스는 화면에 직접 손대지 않고 `Host` 인터페이스(화면이 구현)로 요청한다. 화면 필드를 바꾸려면 해당 `Host` 메서드를 찾는다.

## 3. 화면과 클래스 연결

```
LoginActivity ── HttpHelper ─▶ manager_login.jsp, search_warehouse.jsp
      │            DBHandler.createquery*  (로컬 테이블 생성)
      ▼
MainActivity ── ProgressDlgShipSearch ─▶ ProgressDlgBarcodeSearch ─▶ ProgressDlgGoodsWetSearch
      │                                                                   └─ UnknownAdapter 팝업
      ▼
BixolonShipmentActivity (HoneywellScannerActivity 상속)
      ├─ ShipmentModeFactory → ShipmentMode (마트별)
      ├─ ScanProcessor (ScanState, ScanHost)
      │     ├─ BarcodeInfoFinder → DBHandler(TB_BARCODE_INFO)
      │     └─ BarcodeParser
      ├─ wet_data_insert → mode.insertGoodsWet (DBHandler) → mode.printOnSave
      │                                                        └─ LabelPrintHelper → print/label/*
      │                                                             └─ BixolonSocketPrinter
      ├─ ShipSelectTask / ShipmentSendTask / PrintConnectTask / PrintDisconnectTask
      └─ WetDetailDialog (DetailAdapter, SumLabel)
```

## 4. 무엇을 바꾸려면 어디를 보나

| 바꿀 것 | 볼 곳 |
|------|------|
| 서버 주소 | `common/Common.java` `BASE_URL` |
| 출하대상 조회 조건 | 앱 `common/ProgressDlgShipSearch.java`(WHERE 문자열) **+** 마트별 `search_*.jsp` |
| 응답 칸 추가·순서 | JSP `out.println` 순서 **+** `ProgressDlg*Search`의 `temp[N]` **+** `Shipments_Info`·`DBInfo`·`DBHandler`(CREATE·INSERT·SELECT) — 06 문서 9장 검증 방식대로 |
| 마트별 동작 (중복 확인, 소비기한, 중량 자릿수, 전송 방식·주소) | `shipment/mode/<마트>Mode.java` |
| 스캔 흐름·차단 조건 | `shipment/scan/ScanProcessor.java` |
| 품목 매칭 / 중량 추출 | `shipment/scan/BarcodeInfoFinder.java` / `BarcodeParser.java` |
| 라벨 좌표·내용 | `print/label/<마트>/Label<타입>.java` |
| 새 바코드타입 | 해당 마트 라벨 인터페이스 구현 클래스 추가 + `LabelPrintHelper`의 `switch`에 case 추가 |
| 계근 저장 항목 | `wet_data_insert`(`BixolonShipmentActivity`) + `DBHandler.insertqueryGoodsWet*` |
| 전송 패킷 | `shipment/task/ShipmentSendTask.java` + `insert_goods_wet*.jsp` (06 문서 7장) |
| 계근 상세 팝업 | `shipment/dialog/WetDetailDialog.java` |
| 메인 버튼·메뉴 | `res/layout/activity_main.xml`, `res/menu/main.xml`, `MainActivity.onClick` |
| 스캐너 수신 | `scanner/HoneywellScannerActivity.java` |
| 프린터 연결 | `print/BixolonSocketPrinter.java`, `shipment/task/PrintConnectTask.java` |
| 새 마트 추가 | `Common` searchType 상수, 메인 버튼, `ProgressDlgShipSearch`·`ProgressDlgBarcodeSearch` 분기, `Mode` 구현 + `ShipmentModeFactory`, 라벨 클래스, 조회·전송 JSP |

### 4.1 수정 원칙
- **원본과 같은 동작이 기준**이다(04 문서 1.2). 동작을 바꾸면 04 문서에 결정과 근거를 남긴다.
- 구조 정리는 동작이 그대로인지 확인한다. 라벨은 바꾸기 전후 **출력 바이트를 비교**해 같음을 확인해 왔다(개발/75·76).
- 생산(1·7) 관련 코드는 미사용이지만 지우지 않기로 했다. `ShipmentActivity`도 마찬가지다.
- `ShipmentActivity`에는 `Common`과 겹치는 상수가 남아 있다. 진입 경로가 없는 파일이라 정리 대상에서 뺐다.
