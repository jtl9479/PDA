# 바코드정보 없는 상품목록 팝업

**작성일**: 2026-04-03

---

## 개요

이마트 출하대상받기 완료 후 **항상 표시**되는 팝업. 서버에 바코드 정보가 등록되지 않은 상품 목록을 보여준다.

---

## 표시 시점

```
① ProgressDlgShipSearch (출하대상 조회)
    ↓
② ProgressDlgBarcodeSearch (바코드 정보 조회)
    ↓ onPostExecute: list_unknown 수집
③ ProgressDlgGoodsWetSearch (계근 내역 조회)
    ↓ onPostExecute: show_unknownDialog(list_unknown) — 항상 호출
[팝업 표시]
```

---

## 동작 로직

### ProgressDlgBarcodeSearch.onPostExecute (172~198행)

1. TB_SHIPMENT에서 추출한 `PACKER_PRODUCT_CODE` 목록(`list_code_info`)과 서버에서 받은 바코드 정보(`list_received_bi`) 비교
2. 서버에서 받지 못한 PACKER_PRODUCT_CODE → `list_unknown_bi`에 추가

```java
for (String[] s : list_code_info) {
    int iCount = 0;
    String req_code = s[0];
    for (int i = 0; i < list_received_bi.size(); i++) {
        if (req_code.equals(list_received_bi.get(i).getPACKER_PRODUCT_CODE())) {
            break;  // 서버에서 받음
        }
        iCount++;
    }
    if (iCount == list_received_bi.size()) {
        // 서버에서 받지 못함 → unknown 목록에 추가
        list_unknown_bi.add(temp);
    }
}
```

### ProgressDlgGoodsWetSearch.onPostExecute (159행)

```java
show_unknownDialog(list_unknown);  // list_unknown 크기와 상관없이 항상 호출
```

## 팝업 상태별 의미

| 상태 | 의미 |
|------|------|
| 빈 팝업 (상품 없음) | 모든 상품의 바코드 정보가 서버에서 정상 조회됨 |
| 상품 목록 표시 | 해당 상품은 서버에 바코드 정보 미등록 → 계근 시 문제 가능 |

---

## 비고

- 팝업은 `list_unknown` 크기와 상관없이 **항상 표시**됨 (원본 동작 동일)
- 팝업에 표시되는 상품은 `PACKER_PRODUCT_CODE`와 `ITEM_NAME`
- 팝업 닫으면 출하대상받기 완료
