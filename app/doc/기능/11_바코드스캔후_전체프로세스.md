# 바코드 스캔 후 전체 프로세스

**작성일**: 2026-04-06

---

## 개요

PDA에서 바코드를 스캔한 후 최종 처리(DB 저장, 라벨 출력, 화면 갱신)까지의 전체 흐름을 정리한다.
바코드 스캔은 **2단계 스캔 프로세스**로 동작한다.

---

## 1. 전체 흐름 요약

```
[PDA 바코드 스캔]
    ↓
[HoneywellScannerActivity.m_brc] BroadcastReceiver 수신 (500ms 중복방지)
    ↓
[BixolonShipmentActivity.setMessage()] work_flag에 따라 분기
    ↓
[setBarcodeMsg()] ← 핵심 처리 메서드
    ↓
┌─ scan_flag=true (1차: 상품 바코드 스캔) ──────────────────┐
│  find_PackerProduct() → 바코드에서 패커상품코드 추출       │
│  DBHandler.selectqueryBarcodeInfo() → 바코드 정보 DB 조회  │
│  중복 스캔 체크 (duplicatequeryGoodsWet_check)             │
│  ProgressDlgShipSelect → 출하 대상 목록 조회/표시          │
│  scan_flag = false로 전환 → 2차 스캔 대기                  │
└────────────────────────────────────────────────────────────┘
    ↓ (2차 바코드 스캔)
┌─ scan_flag=false (2차: BL번호 스캔) ──────────────────────┐
│  BL번호 일치 확인                                          │
│  ITEM_TYPE별 중량 추출                                     │
│  LB→KG 환산 (필요시 x0.453592)                            │
│  wet_data_insert() → S_GOODS_WET 테이블 저장               │
│  라벨 출력 (print_bool=true일 때)                          │
│  화면 업데이트 (수량/중량 카운트, ListView 갱신)           │
└────────────────────────────────────────────────────────────┘
```

## 2. 단계별 상세

### 2.1 바코드 수신 (HoneywellScannerActivity)

**파일**: `HoneywellScannerActivity.java:215-246`

- **수신 메커니즘**: BroadcastReceiver (`m_brc`)
- **Action**: `com.honeywell.scantointent.intent.action.BARCODE_DATA`
- **데이터 추출 키**: `com.honeywell.scantointent.intent.extra.DATA`

```java
BroadcastReceiver m_brc = new BroadcastReceiver() {
    @Override
    public void onReceive(Context context, Intent intent) {
        String action = intent.getAction();
        if (ACTION_BARCODE_DATA.equals(action)) {
            String receive_data = intent.getStringExtra(EXTRA_BARCODE_DATA);
            // 500ms 내 동일 바코드 무시 (디바운싱)
            setMessage(receive_data);  // 하위 Activity에서 오버라이드
        }
    }
};
```

**등록**: `onCreate()`에서 IntentFilter로 등록 (106줄)

### 2.4 setBarcodeMsg() - 핵심 처리 (1차: 상품 바코드)

**파일**: `BixolonShipmentActivity.java:1161-1552`

#### scan_flag = true (상품 바코드 스캔)

```
setBarcodeMsg(바코드)
    ↓
find_PackerProduct(바코드)
    ↓
find_work_info(바코드, true)
    ↓ DB에서 TB_BARCODE_INFO 전체 조회
    ↓ 바코드에서 BARCODEGOODS 위치 추출 (substring)
    ↓ 일치하는 PACKER_PRODUCT_CODE 반환
    ↓
중복 스캔 체크 (duplicatequeryGoodsWet_check)
    ↓
ProgressDlgShipSelect 실행 (출하 대상 목록 조회)
    ↓
scan_flag = false로 전환
```

#### find_PackerProduct() / find_work_info()

**파일**: `BixolonShipmentActivity.java:1773-1884`

```java
private String find_work_info(String req, boolean type) {
    ArrayList<Barcodes_Info> list_barcode_info = DBHandler.selectqueryBarcodeInfo(this);

    for (Barcodes_Info bi : list_barcode_info) {
        String bg = bi.getBARCODEGOODS();
        String bg_from = bi.getBARCODEGOODS_FROM();
        String bg_to = bi.getBARCODEGOODS_TO();

        // 바코드에서 특정 위치의 상품코드 추출
        String temp_bg = req.substring(
            Integer.parseInt(bg_from) - 1,
            Integer.parseInt(bg_to)
        );

        if (temp_bg.equals(bg)) {  // 일치하는 상품 찾음
            work_item_bi_info = bi;
            return bi.getPACKER_PRODUCT_CODE();
        }
    }
}
```

### 2.5 setBarcodeMsg() - 핵심 처리 (2차: BL번호 스캔)

**파일**: `BixolonShipmentActivity.java:1372-1539`

#### scan_flag = false (BL번호 스캔)

```
setBarcodeMsg(BL번호)
    ↓
BL번호 일치 확인
    ↓
중복 체크 (duplicatequeryGoodsWet)
    ↓
ITEM_TYPE별 중량 추출
    ↓
wet_data_insert() → DB 저장 + 라벨 출력 + 화면 갱신
```

#### ITEM_TYPE별 중량 처리

| ITEM_TYPE | 중량 추출 방식 | 설명 |
|:---------:|---------------|------|
| W | 바코드에서 중량 위치 추출 | 바코드 계근 |
| HW | 바코드에서 중량 위치 추출 | 홈플러스 바코드 계근 |
| S | 바코드에서 중량 추출 | 저울 계근 |
| J | `arSM.get().getPACKWEIGHT()` | 지정 중량 사용 |
| B | 바코드에서 중량 추출 (소수점 처리 다름) | 홈플러스 비정량 |

#### 중량 환산 로직

```java
// Zero Point 적용
item_pow = Math.pow(10, Integer.parseInt(work_item_bi_info.getZEROPOINT()));
item_weight_double = Double.parseDouble(item_weight) / item_pow;

// LB→KG 환산 (필요시)
if ("LB".equals(work_item_bi_info.getBASEUNIT())) {
    double temp_weight_double = item_weight_double * 0.453592;
    item_weight_double = Math.floor(temp_weight_double * item_pow) / item_pow;
}
```

### 2.6 wet_data_insert() - 계근 데이터 저장

**파일**: `BixolonShipmentActivity.java:1600-1746`

#### 처리 흐름

```
wet_data_insert(weight_str, weight_double, making_date, box_serial)
    ↓
1. 요청수량 완료 여부 체크 (GI_REQ_PKG == PACKING_QTY이면 return)
    ↓
2. Goodswets_Info 객체 생성 (GI_D_ID, WEIGHT, BARCODE, MAKINGDATE, BOXSERIAL 등)
    ↓
3. 출하 유형별 DB 저장
    ↓
4. 계근수량/중량 업데이트 (PACKING_QTY+1, GI_QTY+weight)
    ↓
5. 라벨 출력 (print_bool=true일 때)
    ↓
6. 화면 업데이트
```

#### 출하 유형별 DB 저장

| searchType | 메서드 | 특징 |
|:----------:|--------|------|
| 이마트(0), 도매(3), 생산(1) | `DBHandler.insertqueryGoodsWet()` | 기본 저장 |
| 홈플러스(2, 5) | `DBHandler.insertqueryGoodsWetHomeplus()` | maxBoxOrder 기반 박스 번호 |
| 롯데(6) | `DBHandler.insertqueryGoodsWetLotte()` | lotte_TryCount 박스 순번 (1-99 순환) |

**저장 테이블**: `S_GOODS_WET`
