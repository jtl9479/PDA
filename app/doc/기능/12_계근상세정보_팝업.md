# 계근 상세정보 팝업 (show_wetDetailDialog)

**작성일**: 2026-04-07

---

## 개요

계근입력화면(BixolonShipmentActivity)에서 **선택 버튼** 클릭 시 표시되는 팝업.
선택된 지점의 계근 상세 현황(박스별 중량)을 확인하고, 개별 삭제/라벨 재출력/합산 라벨 출력이 가능하다.

---

## 1. 전체 흐름

```
[계근입력화면] 리스트에서 체크박스로 지점 선택
    ↓
[선택 버튼] 클릭 (btn_select)
    ↓
선택된 지점 확인 (sListAdapter.cbStatus)
    ↓ 선택됨                    ↓ 미선택
show_wetDetailDialog() 호출     "지점을 선택해주세요" Toast + 진동
    ↓
TB_GOODS_WET 조회 (selectqueryGoodsWet)
    ↓
계근 상세정보 팝업 표시
    ↓
[뒤로] / [삭제] / [합산] 버튼 동작
```

## 2. 상세 동작

### 2.1 선택 버튼 클릭 (팝업 진입)

**파일**: `BixolonShipmentActivity.java:794~814줄`

```java
private View.OnClickListener selectBtnListener = new View.OnClickListener() {
    public void onClick(View v) {
        setSelect_Position(-1);
        for (int i = 0; i < sListAdapter.cbStatus.size(); i++) {
            if (sListAdapter.cbStatus.get(i)) {
                setSelect_Position(i);
                break;
            }
        }
        if (getSelect_Position() != -1) {
            show_wetDetailDialog(arSM.get(getSelect_Position()), work_item_bi_info, getSelect_Position());
            set_scanFlag(true);
            work_ppcode = "";
        } else {
            Toast.makeText(getApplicationContext(), "지점을 선택해주세요.", Toast.LENGTH_SHORT).show();
            vibrator.vibrate(1000);
        }
    }
};
```

- 리스트에서 체크박스가 true인 첫 번째 항목을 `select_position`으로 설정
- 선택된 항목이 있으면 `show_wetDetailDialog()` 호출
- 선택된 항목이 없으면 Toast 경고 + 진동

### 2.2 팝업 표시 (show_wetDetailDialog)

**파일**: `BixolonShipmentActivity.java:3003~3191줄`

```java
private void show_wetDetailDialog(Shipments_Info si, Barcodes_Info bi, int position)
```

- **레이아웃**: `dialog_detailshipment.xml`
- **파라미터**: 선택된 지점의 Shipments_Info, Barcodes_Info, 리스트 위치

#### 팝업 상단 정보 표시

| 항목 | 데이터 소스 | 비고 |
|------|------------|------|
| 지점명 | si.getCLIENTNAME() | 읽기전용 |

| 중량 | GI_REQ_QTY / GI_QTY | 요청중량 / 계근중량 |

#### 계근 리스트 (detail_list)

|------|------|------|

**리스트 어댑터**: `DetailAdapter.java`

## 3. 버튼별 동작

### 3.1 뒤로 버튼 (detail_btn_back)

**파일**: `BixolonShipmentActivity.java:3030~3051줄`

| 순서 | 동작 |
|:----:|------|
| 1 | 팝업 닫기 (`detail_dialog.dismiss()`) |
| 2 | dialog_flag = false |
| 3 | 모든 체크박스 초기화 (cbStatus = false) |
| 4 | 바코드/수량/중량 입력창 초기화 |
| 5 | ProgressDlgShipSelect 재조회 (work_flag에 따라 분기) |

**work_flag별 재조회 분기**:

| work_flag | 모드 | 재조회 기준 |
|:---------:|------|------------|
| 1 | 바코드스캔 | 센터명 + work_ppcode (상품코드) |
| 0 | 수기입력 | 센터명 + work_bl_no (BL번호) |
| 2 | 상품코드 | 센터명 + work_bl_no (BL번호) |

### 3.2 삭제 버튼 (detail_btn_delete)

**파일**: `BixolonShipmentActivity.java:3053~3076줄`

```
계근 리스트에서 체크박스 선택 → 삭제 버튼 클릭
    ↓
list_gi_info.size() == 0 → "삭제할 항목이 없습니다" Toast + 진동
    ↓ size > 0
체크된 항목 수집 (detailAdapter.cbStatus)
    ↓
list_delete.size() > 0 → deleteQuestionDialog() 호출
    ↓ size == 0
"삭제할 항목을 선택하세요" Toast + 진동
```

#### 삭제 확인 다이얼로그 (deleteQuestionDialog)

**파일**: `BixolonShipmentActivity.java:3198~3248줄`

- "정말 삭제하시겠습니까?" 확인/취소 다이얼로그
- **삭제 처리**:
  1. 선택된 항목을 역순(뒤→앞)으로 삭제
  2. `DBHandler.deletequerySelectGoodsWet(GI_D_ID, BARCODE, BOX_CNT, GI_L_ID)` → TB_GOODS_WET에서 DELETE
  3. `refresh_delete(WEIGHT)` → arSM의 PACKING_QTY -1, GI_QTY - 삭제중량 반영
  4. 전송 버튼 비활성화 (`btn_send.setEnabled(false)`)
  5. `detail_btn_back.performClick()` → 뒤로 버튼 자동 클릭 (팝업 닫기 + 리스트 재조회)

#### 삭제 제한

**파일**: `DetailAdapter.java:130~133줄`

```java
if (arSrc.get(pos).getSAVE_TYPE().equals("Y")) {
    Toast.makeText(mContext, "전송이 완료된 상품은\n삭제할 수 없습니다.", Toast.LENGTH_SHORT).show();
    return;
}
```

- SAVE_TYPE="Y"(전송 완료)인 항목은 체크박스 선택 불가

### 3.3 합산 버튼 (detail_btn_sum)

**파일**: `BixolonShipmentActivity.java:3078~3179줄`

```
합산 버튼 클릭
    ↓
list_gi_info.size() == 0 → "합산할 항목이 없습니다" Toast + 진동
    ↓ size > 0
SLCS 명령어로 합계 라벨 인쇄
```

#### 합산 라벨 출력 규격

| 항목 | 값 |
|------|-----|
| 라벨 크기 | 576 x 460 도트 |
| 페이지당 항목 수 | 36개 (6열 x 6행) |
| 개별 중량 폰트 | 40 x 40 |
| 총 중량 폰트 | 60 x 60 |
| 총 중량 위치 | (100, 350) |
| 인코딩 | EUC-KR |

#### 합산 라벨 출력 로직

1. 개별 중량을 6열 x 6행으로 배치 (동적 좌표 계산)
2. 36개마다 페이지별 총 중량 출력 후 라벨 인쇄
3. 마지막 페이지는 36개 미만이어도 총 중량 출력 후 인쇄
4. 총 중량은 소수점 둘째자리에서 버림 후 소수점 첫째자리까지 표시

### 3.4 출력 버튼 (리스트 행별 재출력)

**파일**: `DetailAdapter.java:147~159줄` → `BixolonShipmentActivity.java:929~948줄`

- 각 계근 행의 **출력** 버튼 클릭 시 해당 박스의 라벨을 **재출력**
- `MESSAGE_REPRINT(5)` 메시지를 mHandler로 전송
- 전달 데이터: WEIGHT, MAKINGDATE, BOX_ORDER

| searchType | 출력 메서드 |
|:----------:|------------|
| 홈플러스/홈플비정량 | `labelPrintHelper.setHomeplusPrinting(weight, si, true, callback)` |
| 롯데 | `labelPrintHelper.setPrintingLotte(weight, si, true, makingDate, boxOrder, type, callback)` |
| 생산라벨 | `labelPrintHelper.setPrinting_prod(weight, si, true, callback)` |
| 이마트/기타 | `labelPrintHelper.setPrinting(weight, si, true, makingDate, bi, si, type, callback)` |

- 재출력 시 `reprint=true` 파라미터로 호출 (신규 출력과 구분)
- `Common.printer_setting=false` 또는 `Common.print_bool=false`이면 출력 버튼 비활성화

## 6. 주의사항

- 전송 완료(SAVE_TYPE="Y") 항목은 삭제 불가 (DetailAdapter에서 체크박스 선택 차단)
- 삭제 후 전송 버튼이 비활성화됨 (재계근 필요)
- 합산 라벨은 전체 list_gi_info 대상 (체크박스 선택 무관)
- 프린터 미연결(Common.printer_setting=false) 또는 출력 비활성화(Common.print_bool=false) 시 출력 버튼 비활성화
