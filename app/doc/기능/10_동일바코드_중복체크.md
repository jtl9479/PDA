# 동일 바코드 중복 체크

**작성일**: 2026-04-03

---

## 개요

바코드 스캔 시 동일한 바코드가 이미 계근되었는지 확인하는 로직. 분기에 따라 중복 체크가 적용되거나 무시된다.

---

## 분기별 동작

### 1. 최초 스캔 (work_ppcode == "")

**BixolonShipmentActivity.java:1201~1208**

```java
if (work_ppcode.equals("")) {
    boolean dup = DBHandler.duplicatequeryGoodsWet_check(getApplicationContext(), msg);
    // ★ dup 결과를 체크하지 않고 그대로 진행
    work_ppcode = find_ppcode;
    work_item_fullbarcode = msg;
    new ProgressDlgShipSelect(...).execute();
}
```

| 항목 | 내용 |
|------|------|
| 중복 체크 | `duplicatequeryGoodsWet_check` 호출하지만 결과 **무시** |
| 동작 | 중복이어도 그대로 진행 |
| 원본 동일 | **YES** — 원본에서 `if (dup)` 블록이 의도적으로 주석 처리 (652~660행) |
| 관련 오류 | `app/doc/오류/01_계근완료후_동일바코드_라벨재출력_버그.md` |

### 2. 같은 상품 재스캔 (work_ppcode == find_ppcode)

**BixolonShipmentActivity.java:1209~1224**

```java
} else if (!work_ppcode.equals("") && work_ppcode.equals(find_ppcode)) {
    boolean dup = DBHandler.duplicatequeryGoodsWet_check(getApplicationContext(), work_item_fullbarcode);

    if (Common.searchType.equals(SEARCH_TYPE_NONFIXED) || Common.searchType.equals(SEARCH_TYPE_HOMEPLUS_NONFIXED)) {
        dup = false;  // 비정량은 중복 체크 제외
    }

    if (dup) {
        Toast "이미 스캔한 바코드입니다" → 차단, return
    }
}
```

| 항목 | 내용 |
|------|------|
| 중복 체크 | `duplicatequeryGoodsWet_check` 호출하고 결과 **적용** |
| 동작 | 중복이면 Toast + 진동 + return으로 **차단** |
| 비정량 예외 | searchType 4, 5는 `dup = false` 강제 (중복 허용) |
| 원본 동일 | **YES** |
