## 1. 개요

출하 계근 화면에서 사용하는 주요 데이터의 흐름을 설명한다.

| 변수 | 타입 | 용도 |
|------|------|------|
| `arSM` | `ArrayList<Shipments_Info>` | 출하대상 목록 (계근할 상품 리스트) |
| `current_work_position` | `int` | 현재 작업 중인 출하대상의 인덱스 |
| `work_item_bi_info` | `Barcodes_Info` | 현재 작업 상품의 바코드 파싱 정보 |
| `edit_barcode` | `EditText` | 바코드/중량 입력 필드 (UI 컴포넌트) |

## 2. arSM (출하대상 목록)

### 2.1 데이터 흐름도

```
┌─────────────────┐     HTTP      ┌─────────────────┐     파싱      ┌─────────────────┐
│   서버 DB       │ ───────────▶ │  receiveData    │ ───────────▶ │  list_si_info   │
│ VW_PDA_WID_LIST │   API 호출   │  (문자열 응답)   │   split()    │  (ArrayList)    │
└─────────────────┘              └─────────────────┘              └─────────────────┘
                                                                          │
                                                                          ▼ INSERT
┌─────────────────┐     조회      ┌─────────────────┐    저장      ┌─────────────────┐
│      arSM       │ ◀─────────── │   DBHandler     │ ◀─────────── │   TB_SHIPMENT   │
│  (ArrayList)    │  SELECT      │ selectquery     │              │   (로컬 SQLite) │
└─────────────────┘              │ Shipment()      │              └─────────────────┘
                                 └─────────────────┘
```

## 4. current_work_position (현재 작업 인덱스)

### 4.1 정의

```java
// BixolonShipmentActivity.java (333줄)
private int current_work_position;

// 331줄 주석
/**
 * -1: 미선택, 0~n: arSM 리스트 인덱스
 */
```

### 4.2 개념도

```
arSM (출하대상 리스트)
┌─────────────────────────────────────┐
│ [0] 롯데마트 강남점 - 한우등심      │
│ [1] 롯데마트 잠실점 - 한우등심      │  ◀── current_work_position = 1 (현재 작업 중)
│ [2] 롯데마트 목동점 - 한우등심      │
│ [3] 이마트 성수점 - 한우채끝        │
└─────────────────────────────────────┘
```

### 4.3 값의 의미

| 값 | 의미 | 상태 |
|----|------|------|
| `-1` | 미선택 | 초기 상태, 바코드 스캔 대기 |
| `0 ~ n` | arSM 리스트 인덱스 | 해당 인덱스의 출하대상 작업 중 |

### 4.4 할당 시점

**바코드 스캔 시** 매칭되는 출하대상의 인덱스로 설정

**파일**: `BixolonShipmentActivity.java` (1147-1161줄)

```java
// 바코드 스캔 후 출하대상 매칭
for (int i = 0; i < arSM.size(); i++) {
    // BL_NO와 계근 미완료 조건으로 매칭
    if (temp_bl_no.equals(arSM.get(i).getBL_NO())
        && !arSM.get(i).getGI_REQ_PKG().equals(String.valueOf(arSM.get(i).getPACKING_QTY()))) {
        current_work_position = i;  // 매칭된 위치 저장
        break;
    }
}

// 매칭 실패 시
if (current_work_position == -1) {
    // "해당 상품이 없습니다" 알림
}
```

### 5.1 정의

### 5.2 용도

**하나의 입력 필드**가 `work_flag` 값에 따라 **두 가지 용도**로 사용된다.

| work_flag | 모드 | edit_barcode 용도 | 입력 예시 |

### 5.6 LabelPrintHelper 분리 시 처리

`LabelPrintHelper`는 별도 클래스이므로 Activity의 UI 컴포넌트에 직접 접근 불가.
**콜백 인터페이스**로 처리한다.

```java
// PrinterCallback 인터페이스
public interface PrinterCallback {
    void sendData(byte[] data);      // 프린터 데이터 전송
    void clearBarcodeInput();        // 바코드 입력창 초기화
}

// BixolonShipmentActivity에서 구현
printerCallback = new PrinterCallback() {
    @Override
    public void clearBarcodeInput() {
        edit_barcode.setText("");    // Activity에서 직접 처리
    }
};

// LabelPrintHelper에서 호출
public void setPrinting(..., PrinterCallback callback) {
    // ... 라벨 출력 처리
    callback.clearBarcodeInput();  // 콜백으로 입력창 초기화 요청
}
```
