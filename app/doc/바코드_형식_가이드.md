## 4. 홈플러스 바코드 형식

### H0 - 홈플러스 (setHomeplusPrinting)

홈플러스는 **바코드를 생성하지 않고**, 라벨에 텍스트 정보만 출력합니다.

**분기 방식**: BARCODE_TYPE이 아닌 **searchType**으로 분기
- searchType = 2: 홈플러스 출하
- searchType = 5: 홈플러스 비정량

| 출력 항목 | 변수 |
|----------|------|
| 지점명 | pointName (CLIENTNAME) |
| 지점코드 | pointCode (EMARTLOGIS_CODE) / storeCode (STORE_CODE) |
| 상품명 | EMARTITEM |
| 차량코드 | CT_CODE |
| 중량 | weight_double |
| 수입식별번호 | IMPORT_ID_NO (뒤 4자리) |

**주의**: HW는 BARCODE_TYPE이 아닌 **ITEM_TYPE** 상수입니다 (원료육 구분용).
