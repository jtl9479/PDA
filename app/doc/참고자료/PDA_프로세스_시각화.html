4마트사별 상세 프로세스

탭 클릭 시 해당 마트사 전용 화면으로 전환됩니다. 모든 마트사는 동일한 6종 정보 타일 + 5단계 흐름 + WHERE 조건/특이사항 구성으로 정리되어 서로 비교하기 쉽습니다. (탭의 ● : 초록=전환완료 · 주황=전환대기 · 빨강=이슈 보유)

WHERE 박스는 SELECT의 WHERE절만 발췌한 것입니다. 각 쿼리의 JOIN ON절에 다음 추가 필터가 더 있습니다: ① B.마트사구분 = '?' — CO_거래처MASTER에 거는 2차 마트사구분 필터 (0·2·4·5, WHERE의 H.마트사구분과 별개) · ② C.대분류='043'(제품용도 명칭)·C1.대분류='Q14'(원산지 명칭) — 코드명칭 조회용 JOIN (0·4·5) · ③ G2.거래처코드 != H.출고거래처 — M2 대체 매출처품목코드매핑 폴백 (0·2·4·5·6) · ④ 롯데(6) LAST_BOX_ORDER 서브쿼리 W.박스순번 IS NOT NULL. 도매(3)는 거래처MASTER에 마트사구분 필터 없이 WHERE H.마트사구분=''만 사용합니다.
