# PDA기기로 라벨 입력하면 빅솔론 프린터 출력

---

## 개요

- **작성일**: 2026-01-12
- **최종 수정일**: 2026-01-12
- **목적**: PDA에서 바코드 스캔 → 계근 데이터 입력 → 빅솔론 프린터 라벨 출력 전체 플로우 테스트
- **대상 파일**:
  - `scanner/HoneywellScannerActivity.java` - 바코드 스캔
  - `BixolonShipmentActivity.java` - 계근 입력 및 SLCS 라벨 생성
  - `print/BixolonSocketPrinter.java` - 프린터 통신

---

## 전체 플로우

```
[PDA 바코드 스캔]
    ↓ HoneywellScannerActivity.setMessage()
[BixolonShipmentActivity]
    ↓ 바코드 파싱 → 계근 데이터 생성
[SLCS 명령어 생성]
    ↓ slcsInit(), slcsText(), slcsBarcode(), slcsPrint()
[BixolonSocketPrinter.sendCommand()]
    ↓ Bluetooth SPP
[빅솔론 프린터 라벨 출력]
```
