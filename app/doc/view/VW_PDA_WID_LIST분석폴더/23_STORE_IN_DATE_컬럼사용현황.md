## 5. 사용 코드

### 5.1 서버 응답 파싱

**파일**: ProgressDlgShipSearch.java (Line 290)

```java
si.setSTORE_IN_DATE(temp[22].toString());    // 입고일자
```

### 5.2 라벨 출력 - 날짜 형식 변환

**파일**: BixolonShipmentActivity.java (Line 2572)

```java
Log.i(TAG, "=====================납품일자==================" + si.getSTORE_IN_DATE());

// "YYYYMMDD" → "YYYY년 MM월 DD일" 형식 변환
String tempDate = si.getSTORE_IN_DATE().substring(0,4) + "년 "
                + si.getSTORE_IN_DATE().substring(4,6) + "월 "
                + si.getSTORE_IN_DATE().substring(6,8) + "일";

// 예: "20260115" → "2026년 01월 15일"
```

### 5.3 라벨 출력 - 납품일자 인쇄

**파일**: BixolonShipmentActivity.java (Line 2573, 2590 등)

```java
// M3/M4 타입
slcsCmd.append(slcsText(15, 348, 30, 30, "납품일자 : " + tempDate));

// 기타 타입
slcsCmd.append(slcsText(15, 328, 30, 30, "납품일자 : " + tempDate));

// 비정량 타입
slcsCmd.append(slcsText(170, 402, 40, 40, tempDate));
```

## 9. 결론

**상태**: ✅ 필수 (삭제 불가)

STORE_IN_DATE는 **라벨 출력의 필수 컬럼**으로:
- "YYYYMMDD" 형식으로 저장
- 라벨 출력 시 **"YYYY년 MM월 DD일"** 형식으로 변환
- 바코드 타입별로 **다른 위치에 출력**
- GI_REQ_DATE(출하요청일)와는 별개 컬럼
