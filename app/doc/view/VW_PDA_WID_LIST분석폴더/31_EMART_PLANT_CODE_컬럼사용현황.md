### 4.2 미트센터 라벨 분기 조건

**파일**: BixolonShipmentActivity.java (Line 2618, 2671)

```java
// ========== 미트센터 +공장코드 라벨 ==========
// 조건: M0 && 미트센터 && 기본지점코드 && 공장코드 있음
if (si.getBARCODE_TYPE().equals(BARCODE_TYPE_M0)
    && si.getSTORE_CODE().equals(MEAT_CENTER_STORE_CODE)      // "9231"
    && si.getEMARTLOGIS_CODE().equals(LOGIS_CODE_DEFAULT)     // 기본 지점코드
    && !si.getEMART_PLANT_CODE().equals("")) {                // ★ 공장코드 있음
    // "ERP-미트센터출하코드" 라벨 출력
}

// ========== 미트센터 라벨 (공장코드 없음) ==========
// 조건: M0 && 미트센터 && 기본지점코드 아님 && 공장코드 없음
if (si.getBARCODE_TYPE().equals(BARCODE_TYPE_M0)
    && si.getSTORE_CODE().equals(MEAT_CENTER_STORE_CODE)      // "9231"
    && !si.getEMARTLOGIS_CODE().equals(LOGIS_CODE_DEFAULT)    // 기본 지점코드 아님
    && si.getEMART_PLANT_CODE().equals("")) {                 // ★ 공장코드 없음
    // "미트센터출하코드" 라벨 출력
}
```

### 4.3 미트센터 바코드 생성 - 공장코드 포함

// 공장코드가 있는 미트센터 바코드
meatCenterBarcode = si.getEMARTLOGIS_CODE().substring(0, 6)  // 지점코드 6자리

## 11. 결론

**상태**: ✅ 필수 (삭제 불가)

EMART_PLANT_CODE는 **미트센터 라벨 분기의 핵심 컬럼**으로:
- **공장코드 유무**로 라벨 타입 결정
- 있으면: **"ERP-미트센터출하코드"** 라벨
- 없으면: **"미트센터출하코드"** 라벨
- 바코드 끝에 **공장코드 추가**
- M0 + 미트센터(9231) 조건에서만 사용
