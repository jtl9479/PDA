## 개발 일정
1. (이마트출하) 계근입력시작 화면 진입
2. (이마트출하) 계근입력시작 화면 테스트 데이터 임의 생성
3. BixolonShipmentActivity에서 Woosim → Bixolon 코드 변환 │
4. HoneywellScannerActivity.java 허니웰 기준으로 수정
5. 빅솔론 프린터 연동 테스트
6. PDA기기로 라벨 입력하면 빅솔론 프린터 출력 (BixolonSocketPrinter.java에 이미 SLCS 명령어 구현 참조)
7. 이마트 출하 DB 연동

## 원칙
1. 무조건 기존과 동일한 기능으로 동작해야 한다.
2. step별 단위테스트로 합/불합 여부를 정한다.
3. 모든 step 완료 후 통합테스트로 최종 합/불합 여부를 정한다.
4. 임의로 개발을 진행하면 안 된다.
5. 나에게 최우선적으로 말을 하고, 내 지시에 따라서만 진행한다.
6. 모든 개발은 문서화 작업을 먼저 진행 후 확인을 받는다.
   1. 단계별 진행 사항을 알기 위해 체크박스를 만든다.
   2. 각 단계마다 확인을 받은 후 다음 단계로 넘어간다.
   3. 완료된 단계는 체크박스를 체크한다.
   4. "무엇을, 왜, 어떻게" 변경했는지 명확히 명시한다.
   5. 각 step 완료 시 단위테스트를 진행한다.
   6. 이전 step에 대한 회귀테스트도 함께 진행한다.
      - 예외: step 여건 상 오류가 발생할 수 밖에 없는 경우에는 왜 오류가 발생하며 언제 해결되는지 문서에 기록하라
      - 예외: 오류 발생 시 원인과 해결 시점을 설명하는 내용을 문서에 기록하라
7. 주석은 유지보수를 위해 자세하게 작성한다.
8. 모든 진행은 step by step으로 확인 및 재확인하여 정확성을 높인다.
