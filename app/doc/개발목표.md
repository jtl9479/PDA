## 개발 일정
1. (이마트출하) 계근입력시작 화면 진입
2. (이마트출하) 계근입력시작 화면 테스트 데이터 임의 생성
3. BixolonShipmentActivity에서 Woosim → Bixolon 코드 변환 │
4. HoneywellScannerActivity.java 허니웰 기준으로 수정
5. 빅솔론 프린터 연동 테스트
6. PDA기기로 라벨 입력하면 빅솔론 프린터 출력 (BixolonSocketPrinter.java에 이미 SLCS 명령어 구현 참조)
7. 이마트 출하 DB 연동


## 원칙
1. 무조건 기존과 동일한 기능으로 동작해야한다.
2. 테스트는 단위테스트가 아닌 통테기준으로 합/불합여부를 정한다.
3. 임의로 개발을 진행하면 안 된다.
4. 나에게 최우선적으로 말을 하고 나 말에 따라서 진행한다.
5. 모든 개발은 문서화 작업을 먼저 진행 후 나에게 확인을 받는다
    1. 문서에는 단계별 진행 사항을 알기위해 체크박스를 만든다.
    2. 작업은 단계별로 나누고, 각 단계마다 확인을 받은 후 다음 단계로 넘어간다.
    3. 진행이 완료된 단계는 체크박스 체크를 진행한다.
    4. 개발 진행 사항은 "무엇을, 왜, 어떻게" 변경했는지 명확히 명시한다.
6. 변경 사항은 "무엇을, 왜, 어떻게" 변경했는지 명확히 기록한다.
7. 주석은 유지보수를 위하여 자세하게 적어라
8. 모든 진행 사항은 step by step으로 확인 후 재확인을 통해 정확성을 높여라
