## 오늘 해야 할 작업

### 1. 실기기 테스트 이어서 진행 (5단계~)

4단계(계근입력시작)까지 완료. 5단계부터 이어서 진행.

| 순서  | 테스트         | 확인 사항                                  | 상태  |
| :-: | ----------- | -------------------------------------- | :-: |
|  1  | 로그인         | 서버(192.168.0.28:4040) 접속, 창고 목록 조회     |  ✅  |
|  2  | 출하대상받기      | search_shipment.jsp 응답, TB_SHIPMENT 저장 |  ✅  |
|  3  | 출하대상 팝업 확인  | ActionBar "출하대상" 메뉴 → 팝업 표시 (개발24)     |  ✅  |
|  4  | 계근입력시작      | BixolonShipmentActivity 진입, 센터/BL 스피너  |  ✅  |
|  5  | 수기 바코드 입력   | ENTER 누를 때까지 대기하는지 확인 (개발25)           |  ✅  |
|  6  | 바코드 스캔 (1차) | find_PackerProduct() 매칭, 출하대상 리스트 표시   |  ✅  |
|  7  | BL 스캔 (2차)  | 중량 추출, TB_GOODS_WET INSERT             |  ✅  |
|  8  | 라벨 출력       | BIXOLON 프린터 setPrinting()              |  ⏳  |
|  9  | 계근 완료 → 전송  | insert_goods_wet.jsp → SM_출고계근 INSERT  |  ✅  |
| 10  | ERP 데이터 확인  | SM_출고계근 테이블에서 데이터 조회                   |  ⏳  |

### 2. 계근상세정보 팝업 테스트

기능12 문서 기반으로 계근상세정보 팝업 동작 확인.

| 순서  | 테스트           | 확인 사항                                     | 상태  |
| :-: | ------------- | ----------------------------------------- | :-: |
|  1  | 선택 버튼         | 체크박스 선택 후 팝업 표시, 상단 정보(지점명/상품명/수량/중량) 정상  |  ✅  |
|  2  | 계근 리스트        | TB_GOODS_WET 조회, No/박스시리얼/상품코드/중량/유통기한 표시 |  ✅  |
|  3  | 삭제 기능         | 체크 후 삭제 → TB_GOODS_WET DELETE, 수량/중량 반영   |  ✅  |
|  4  | 출력 버튼 (재출력)   | 행별 출력 버튼 → 라벨 재출력 정상                      |  ⏳  |
|  5  | 합산 버튼         | 전체 중량 합산 라벨 출력 정상                         |  ⏳  |
|  6  | 뒤로 버튼         | 팝업 닫기 → 리스트 재조회 정상                        |  ✅  |
|  7  | 전송완료 항목 삭제 불가 | SAVE_TYPE="Y" 항목 체크박스 선택 차단 확인            |  ✅  |

### 3. 테스트 중 오류 발생 시

- 오류 발생 → `app/doc/오류/` 폴더에 문서화
- 수정 필요 시 → `app/doc/개발/` 폴더에 개발 문서 작성 후 진행
