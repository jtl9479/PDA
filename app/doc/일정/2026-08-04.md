## 이슈/메모

- **블로커 해소**: `개발/00_개발진행현황.md` §4.0의 "ERP VIEW 구조 확정 답변 대기"는 조사로 해소됨. `SM_출고머리.출고구분` 실사용값이 `1`(출고)/`2`(반품)/`3`(거래명세)뿐이라 생산투입이 없고, 생산은 `PD_` 모듈로 완전 분리되어 있음이 확인됨.
- **설계 변경**: 계근 결과 적재 테이블을 `SM_출고계근`이 아닌 **`PD_생산계근`(신설)** 으로 분리. `SM_출고계근.출고상세SEQ`/`출고LOTSEQ`는 `SM_출고상세`/`SM_출고LOT` 참조 키라 `PD_` SEQ 투입 시 키 공간이 충돌하기 때문. ERP `hbm2ddl.auto: update` 설정으로 재기동 시 테이블 자동 생성됨.
- **실행 검증 미완 3건**: `Q.회사코드` 컬럼 존재 / `V.BLNO` 컬럼 존재 / `I.비정량여부` 값 분포. Tomcat 로그 `##search_production query :` · `##search_production SQLException :` 으로 확인.
- searchType=7(생산라벨)은 `activity_main.xml:400` TableRow가 `visibility="gone"`으로 UI 미노출 상태 → 오늘 범위에서 제외.
- searchType=1 버튼(`btnproductionlist`, `btnProdWet`, `btnProdWetCalc`)은 **현재 화면에 노출 중**이므로, 전환 완료 전까지 사용 시 SQL 오류가 발생한다.
- `VW_PDA_WID_PRO_4LABEL_LIST`는 DDL 파일 자체가 없어 searchType=7 분석 불가.
