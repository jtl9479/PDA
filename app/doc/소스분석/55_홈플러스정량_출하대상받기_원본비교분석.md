## 4. MSSQL 전환 목표 구조

### 4.1 JSP 변환 목표 (search_shipment_homeplus.jsp)

- Oracle VIEW `VW_PDA_WID_HOMEPLUS_LIST` → **MSSQL 직접 JOIN 쿼리**로 교체
- 출력 컬럼 수: 32개 → **24개** (Java 미파싱 8개 제거, 추가 없음)
- 제거 기준: Java(ProgressDlgShipSearch)에서 파싱하지 않는 컬럼
- 제거 대상 (8개): GI_H_ID, EOI_ID, AMOUNT, GOODS_R_ID, GR_REF_NO, BRANDNAME, PACKERNAME, EMARTLOGIS_NAME
- ORDER BY: HOMPLUS_STORE_CODE 해당 ERP 컬럼으로 유지

### 4.2 Java 파싱 변환 목표 (ProgressDlgShipSearch.java — searchType=2)

- 공통 파싱 (temp[0]~temp[23]): 현재 searchType=2에도 적용 중 → **수정 불필요**
- searchType=2 전용 추가 분기: **불필요** (WH_AREA~GI_L_ID 7개 전부 searchType=2 미사용 확인됨)

### 4.3 WHERE 조건 수정 목표 (ProgressDlgShipSearch.java — searchType=2)

- `AND 창고코드 = '...'` → `AND D.창고코드 = '...'` (테이블 별칭 추가)
