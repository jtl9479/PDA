## 2. 삭제 대상 클래스 (불필요 소스)

### 2.1 확실히 삭제 가능

| 클래스명 | 경로 | 삭제 사유 |
|---------|------|----------|
| **BluetoothPrintService** | `print/BluetoothPrintService.java` | BixolonSocketPrinter로 완전 대체됨. LoginActivity에 import만 있고 실제 사용 안함 |
| **Base64** | `common/Base64.java` | 어디에서도 import/사용되지 않음. Java 내장 Base64 또는 Android util 사용 권장 |

### 2.2 삭제 검토 필요

| 클래스명 | 경로 | 검토 사유 |
|---------|------|----------|
| **ProgressDlgGoodsWetSearch** | `common/ProgressDlgGoodsWetSearch.java` | 현재 호출 코드 없음. 향후 계근 내역 조회 기능 계획 있으면 유지 |
| **ProgressDlgNewBarcodeInfo** | `common/ProgressDlgNewBarcodeInfo.java` | 신규 바코드 추가 기능이 현재 미구현. 향후 기능 추가 계획 있으면 유지 |

## 3. 삭제 작업 가이드

### 3.1 삭제 전 확인사항

```bash
# 해당 클래스가 실제로 사용되지 않는지 grep으로 최종 확인
grep -r "BluetoothPrintService" --include="*.java" app/src/
grep -r "Base64" --include="*.java" app/src/
grep -r "ProgressDlgGoodsWetSearch" --include="*.java" app/src/
grep -r "ProgressDlgNewBarcodeInfo" --include="*.java" app/src/
```

### 3.2 삭제 순서

1. **BluetoothPrintService.java 삭제**
   - 경로: `app/src/main/java/com/highland/app/print/BluetoothPrintService.java`
   - LoginActivity.java에서 import 문 제거 필요

2. **Base64.java 삭제**
   - 경로: `app/src/main/java/com/highland/app/common/Base64.java`
   - 의존성 없음, 바로 삭제 가능

3. **ProgressDlgGoodsWetSearch.java 삭제** (선택)
   - 경로: `app/src/main/java/com/highland/app/common/ProgressDlgGoodsWetSearch.java`

4. **ProgressDlgNewBarcodeInfo.java 삭제** (선택)
   - 경로: `app/src/main/java/com/highland/app/common/ProgressDlgNewBarcodeInfo.java`
