# 출하대상받기 4유형(정량/비정량/도매/생산) 조회조건 종합 정리

## 개요

- **파일 경로**: `app/doc/view/VW_PDA_WID_*` 7개 + JSP 8개
- **패키지**: Oracle DB VIEW (HIGHLAND / INNO 스키마)
- **총 라인 수**: VIEW별 55~300줄 (7개 DDL 기준)
- **타입**: Oracle VIEW DDL + JSP 비교 분석 (4유형 그룹화)
- **작성일**: 2026-04-22

### 4유형 분류 일람

| 유형 | searchType | JSP | VIEW |
|------|:---:|-----|------|
| **1. 마트사 정량** | 0 (이마트), 2 (홈플러스), 6 (롯데) | search_shipment, search_shipment_homeplus, search_shipment_lotte | VW_PDA_WID_LIST, VW_PDA_WID_HOMEPLUS_LIST, VW_PDA_WID_LIST_LOTTE |
| **2. 마트사 비정량** | 4 (이마트 비정량), 5 (홈플러스 비정량) | search_production_nonfixed, search_homeplus_nonfixed | VW_PDA_WID_LIST_NONFIXED, VW_PDA_WID_LIST_NONFIXED_HP |
| **3. 도매** | 3 (도매) | search_shipment_wholesale | VW_PDA_WID_WHOLESALE_LIST |
| **4. 생산** | 1 (생산), 7 (생산 라벨) | search_production, search_production_4label | VW_PDA_WID_PRO_LIST, VW_PDA_WID_PRO_4LABEL_LIST (DDL 부재) |

## 1. 역할

- 8개 출하대상받기 VIEW/JSP를 4유형으로 그룹화하여 공통 조건과 유형별 고유 조건 분리 정리
- 각 유형 간 핵심 식별 조건(타입구분, 발주 연결 여부, 바코드 타입 등) 비교 매트릭스 제공

### 1.2 마트사 정량 공통 조건

3개 VIEW(이마트/홈플/롯데) 모두에 나타나는 조건.

**WHERE 절 공통**:

| 조건 | 이마트(0) | 홈플(2) | 롯데(6) | 비고 |
|------|:---:|:---:|:---:|------|
| `GI_REQ_PKG <> 0` | O | O | O | 3개 VIEW 전체 공통 |
| `GI_REQ_DATE >= TO_CHAR(SYSDATE,'YYYYMMDD')` | O | O | O | 3개 VIEW 전체 공통 |
| `WR.CONTRACT_TYPE <> '40'` (블록1, 해외매입) | O | O | O | 3개 VIEW 전체 공통 |
| `WR.CONTRACT_TYPE = '40'` (블록2, 국내매입) | O | O | O | 3개 VIEW 전체 공통 |

**JOIN ON 절 공통**: 3사(이마트/홈플/롯데) 모두 공통인 조건 없음. 각 마트사별 고유 조건은 1.3·1.4·1.5 참조.

### 1.5 롯데(6) 고유 조건

| 조건                           |               위치               | 설명                                                      |
| ---------------------------- | :----------------------------: | ------------------------------------------------------- |
| `bcc.USER_ID = 'LOTTE'`      |        WHERE (블록1·2 공통)        | 롯데 거래처 담당자 코드로 롯데 구분 — 이마트/홈플에 없는 하드코딩                  |
| `ID.STATUS = '10'`           |        WHERE (블록1·2 공통)        | 출고상세 상태 10인 건만 (이마트/홈플에 없음)                             |
| `beb.BARCODE_TYPE LIKE 'L%'` |       JOIN ON (블록1·2 공통)       | 롯데 전용 바코드 타입 (L로 시작)                                    |
| `BCC.STATUS = 'Y'`           | JOIN ON (`B_CLIENT_CHARGE` 조인) | 롯데 거래처 활성 확인 — 이마트/홈플 VIEW에는 `B_CLIENT_CHARGE` 조인 자체 없음 |
| `beb.ITEM_TYPE = 'W'`        |         WHERE **블록2만**         | 국내매입 블록에만 존재. 블록1에는 없음                                  |
| `PACKING_QTY = 0`            |  **블록1: 없음** / **블록2: 주석처리**   | 이마트·홈플과 달리 미계근 조건이 비활성 또는 부재                            |

### 1.6 마트사 정량 MSSQL 전환 WHERE 절 (확인 요청사항)

원본 Oracle VIEW를 MSSQL ERP 테이블 기반 직접 SQL로 전환.

| 조건                                 |        위치        | 의미                                      |
| ---------------------------------- | :--------------: | --------------------------------------- |
| `H.마트사구분 = '7' / '4' / '6'`         |   JSP 본문 WHERE   | 마트사 식별 (`'7'` 이마트, `'4'` 홈플러스, `'6'` 롯데마트) |
| `D.출고수량 > 0`                       |   JSP 본문 WHERE   | 출고요청 있는 건만 (원본 `ID.GI_REQ_PKG <> 0` 동등) |
| `COALESCE(M1.타입구분, M2.타입구분) = 'W'` |   JSP 본문 WHERE   | 정량(W). M1(직접거래처) → M2(상위거래처) 폴백 (원본 `EB.ITEM_TYPE = 'W'` JOIN ON 동등) |
| 마트사 발주서 INNER JOIN | JOIN | 원본 `EO.EOI_ID IS NOT NULL` 동등 — 마트사별 테이블 연결: 이마트 `SM_마트사발주이마트`, 홈플 `SM_마트사발주홈플러스`, 롯데 `SM_마트사발주롯데마트` |
| `D.회사코드 = '20'`                    | qry_where (앱 전송) | 하이랜드 식별 (회사코드 추가, 신규)                   |
| `D.출고일자 >= '선택일'`                  | qry_where (앱 전송) | PDA에서 선택한 날 이후 (Common.selectDay, 원본 `IH.GI_REQ_DATE >= TO_CHAR(SYSDATE,'YYYYMMDD')` 동등) |
| `D.창고코드 = '...'`                   | qry_where (앱 전송) | 선택한 창고만 조회 (Common.selectWarehouseCode) |
| 미계근 조건 (`SM_출하계근` 집계 COUNT 없는 경우) |   JSP 본문 WHERE   | `SM_출하계근` 테이블에서 출고상세 SEQ 기준 집계하여 COUNT가 없는 건만 (원본 `ID.PACKING_QTY = 0` 동등) |

## 유형 3: 도매 (3)

### 3.1 도매 조회조건 일람

도매(3)는 단일 VIEW(`VW_PDA_WID_WHOLESALE_LIST`)이므로 공통 조건과 도매 전용 조건을 하나의 표로 통합. UNION ALL 2블록 구조(블록1=해외매입, 블록2=국내매입).

| 조건                                              |  위치   | 블록1 (해외) | 블록2 (국내) | 설명                                                                                |
| ----------------------------------------------- | :---: | :------: | :------: | --------------------------------------------------------------------------------- |
| `ID.PACKING_QTY = 0`                            | WHERE |    O     |    O     | 미계근 건만 (정량/비정량 다수와 공통)                                                            |
| `ID.GI_REQ_PKG <> 0`                            | WHERE |    O     |    O     | 출하요청수량 있는 건만 (정량/비정량 다수와 공통)                                                      |
| `WR.CONTRACT_TYPE <> '40'`                      | WHERE |    O     |    X     | 해외매입만 (블록1)                                                                       |
| `WR.CONTRACT_TYPE = '40'`                       | WHERE |    X     |    O     | 국내매입만 (블록2)                                                                       |
| `IH.GI_REQ_DATE >= TO_CHAR(SYSDATE,'YYYYMMDD')` | WHERE |    O     |    O     | 오늘 이후 출하요청일만 (정량/비정량 다수와 공통)                                                      |
| `ID.EOI_ID IS NULL`                             | WHERE |    O     |    O     | **★ 도매 전용** — 마트사 발주서와 **무관한** 건만 (정량/비정량의 `IS NOT NULL`과 정반대)                    |
| `ID.CHECK_YN = 'Y'`                             | WHERE |    O     |    O     | **★ 도매 전용** — 확인(승인)된 건만                                                          |
| `BI.STATUS = 'Y'`                               | WHERE |    O     |    O     | **★ 도매 전용** — B_ITEM 활성 아이템만                                                      |
| `BI.ITEM_TYPE = '10'`                           | WHERE |    O     |    O     | **★ 도매 전용** — 아이템 타입 10인 건만 (B_ITEM 기준, 정량의 B_EMART_BARCODE.ITEM_TYPE='W'와 의미 다름) |
| `IH.SEND_FLAG <> 'N'`                           | WHERE |    O     |    O     | **★ 도매 전용** — 전송 대기 상태가 아닌 건만 (활성 SEND_FLAG, 정량은 주석처리됨)                           |
| `WR.GR_WAREHOUSE_CODE = '4001'`                 | WHERE |    O     |    O     | **★ 도매 전용** — 창고코드 4001(도매 창고)만 (하드코딩)                                            |

### 3.2 도매 MSSQL 전환 WHERE 절 (확인 요청사항)

| 조건                     |        위치        | 의미                             |
| ---------------------- | :--------------: | ------------------------------ |
| `H.마트사구분 = ''`         |   JSP 본문 WHERE   | 도매 식별 (마트사 발주서 무관)             |

| `D.창고코드 = '...'`        | qry_where (앱 전송) | 선택한 창고만 조회 (정량/비정량과 동일 방식, 하드코딩 아님) |
| 미계근 조건 (`SM_출고계근` 기반)  |   JSP 본문 WHERE   | 계근을 진행하지 않은 경우                 |
| `I.원료육여부 = '1'`         |   JSP 본문 WHERE   | 원료육 품목만 (Oracle `BI.ITEM_TYPE='10'` MSSQL 매핑 → `CO_품목코드.원료육여부='1'`) |

### 3.3 도매 확인 필요 사항 (확인 요청사항)

| 의문점                           | 확인 결과 |
| ----------------------------- | ------- |
| **정량/비정량 구분 여부**              | **구분 없음** — 도매는 searchType=3 단일로 정량/비정량 구분 없이 동일하게 진행 |
| **창고코드 4001 한정 여부**           | **한정 없음** — 정량/비정량과 동일하게 qry_where로 동적 전달 (하드코딩 아님) |
| **`BI.ITEM_TYPE = '10'`의 의미** | **`CO_품목코드.원료육여부 = '1'`로 매핑** — Oracle `B_ITEM.ITEM_TYPE='10'`이 MSSQL에서 `CO_품목코드.원료육여부='1'`에 해당. JSP WHERE절에 `AND I.원료육여부 = '1'` 추가 필요 |
