================================================================================
 [문의사항 Q05] 비정량 이마트 M9 바코드 — 기존 정량 M9과 BARCODE_TYPE 코드값 중복
================================================================================


 요청일: 2026-04-29


--------------------------------------------------------------------------------
 1. 질문 요지 (한 줄)
--------------------------------------------------------------------------------

기존 BARCODE_TYPE='M9'(정량 이마트 우육 센터납)이 이미 사용 중인데,
신규로 추가하려는 BARCODE_TYPE='M9'(비정량 이마트)와 코드값이 중복됩니다.


--------------------------------------------------------------------------------
 2. 발견 경위
--------------------------------------------------------------------------------

- 사용자 요청: 비정량 이마트(searchType=4)에 BARCODE_TYPE='M9' 신규 추가
- 코드 분석 결과: 기존 정량 이마트(searchType=0)에서 이미 BARCODE_TYPE='M9' 사용 중
- 동일한 'M9' 코드값을 정량과 비정량 두 용도로 사용하면
    BARCODE_TYPE만으로는 식별 불가


--------------------------------------------------------------------------------
 3. 확인 요청 사항
--------------------------------------------------------------------------------

 [핵심 질문]

 기존 BARCODE_TYPE='M9'(정량 이마트 우육 센터납)을 제거하고,
 비정량 이마트 전용 BARCODE_TYPE='M9'으로 재정의하여 진행해도 됩니까?


--------------------------------------------------------------------------------
 4. 답변 (2026-04-30)
--------------------------------------------------------------------------------

> 기존에 M9은 임시적으로 했던 바코드 타입일 것 같습니다.
> 말씀하신대로 현재 비정량으로 기존타입 제거하고 추가하는게 맞다고 판단됩니다.

 [결론]

  - 기존 정량 M9(이마트 우육 센터납)은 임시 바코드 타입이었던 것으로 확인
  - 기존 정량 M9 제거 + 비정량 전용 BARCODE_TYPE='M9'으로 재정의 진행 OK
  - 개발43 가이드 보완: 정량 M9 분기 제거, 비정량 단독 처리로 변경
