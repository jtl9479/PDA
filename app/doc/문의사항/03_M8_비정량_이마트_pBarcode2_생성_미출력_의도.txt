 [문의사항 Q03] 이마트 비정량(M8) pBarcode2 생성은 되나 라벨 미출력 — 설계 의도 확인
================================================================================


--------------------------------------------------------------------------------
 1. 질문 요지 (한 줄)
--------------------------------------------------------------------------------

이마트 비정량(M8) 라벨 출력 시 pBarcode2(물류코드 기반 바코드)가 코드상 생성은
되지만 실제 라벨에는 인쇄되지 않습니다. 지워도 상관이 없습니까?


--------------------------------------------------------------------------------
 2. 발견 경위
--------------------------------------------------------------------------------

- 실제 LabelPrintHelper.java 출력 로직 분석 결과, M8은 pBarcode만 라벨에
  인쇄되고 pBarcode2는 변수 생성만 됨을 확인
- 동일 switch-case 내 M3/M4/M9는 pBarcode2까지 라벨에 인쇄되는데
  M8만 예외


--------------------------------------------------------------------------------
 3. 기술적 사실 (확정)
--------------------------------------------------------------------------------

[항목 1] M8 case에서 pBarcode/pBarcode2 두 변수 모두 생성
        근거: LabelPrintHelper.java:682~685

[항목 2] pBarcode는 라벨 바코드로 인쇄됨
        근거: LabelPrintHelper.java:811
        -> slcsBarcode(..., pBarcode) 무조건 호출

[항목 3] pBarcode2는 M3/M4/M9에서만 인쇄됨
        근거: LabelPrintHelper.java:832~843

[항목 4] M8은 pBarcode2 인쇄 분기에 포함되지 않음
        근거: 동일 위치 if/else 분기

[항목 5] pBarcode2 로그에는 기록됨
        근거: LabelPrintHelper.java:791
        -> Log.i(... pBarcode2 ...)


 3.1 pBarcode / pBarcode2 실제 코드 (M8)

    case "M8":
        // 이마트 비정량 납품분
        pBarcode    = EMARTITEM_CODE.substring(0,6) + print_weight_str
                      + pCompCode + IMPORT_ID_NO;
        pBarcodeStr = EMARTITEM_CODE.substring(0,6) + " " + print_weight_str
                      + " " + pCompCode + " " + IMPORT_ID_NO;

        pBarcode2    = EMARTLOGIS_CODE.substring(0,6) + IMPORT_ID_NO
                       + print_weight_str + pCompCode;
        pBarcodeStr2 = EMARTLOGIS_CODE.substring(0,6) + " " + print_weight_str
                       + " " + pCompCode + " " + IMPORT_ID_NO;
        break;


 3.2 타 바코드 타입 비교

  ┌────────┬───────────────┬────────────────────────────────┐
  │ 타입   │ pBarcode 인쇄 │ pBarcode2 인쇄                 │
  ├────────┼───────────────┼────────────────────────────────┤
  │ M0     │      O        │ X (생성만, M8과 동일 패턴)     │
  │ M1     │      O        │ X                              │
  │ * M3 * │      O        │ O (라벨에 2개 인쇄)            │
  │ * M4 * │      O        │ O (라벨에 2개 인쇄)            │
  │ * M8 * │      O        │ X (생성만, 인쇄 안 됨)         │
  │ * M9 * │      O        │ O (라벨에 2개 인쇄)            │
  │ E0~E3  │      O        │ X                              │
  └────────┴───────────────┴────────────────────────────────┘

  * M8이 M0/M1/E0~E3와 같은 "1개 인쇄" 그룹에 속함.
    M3/M4/M9와는 다름.


--------------------------------------------------------------------------------
 4. 확인 요청 사항
--------------------------------------------------------------------------------

 [핵심 질문]

 이마트 비정량(M8) 라벨에서 pBarcode2(물류코드 기반 바코드)를
 코드에서 완전히 제거해도 됩니까?

  - 현재 코드상 pBarcode2는 생성만 되고 라벨에 인쇄되지 않습니다.
  - 즉 pBarcode2 생성 코드를 삭제해도 실운영에 영향이 없습니까?
  - 아니면 향후 pBarcode2 인쇄가 필요하므로 남겨두어야 합니까?
