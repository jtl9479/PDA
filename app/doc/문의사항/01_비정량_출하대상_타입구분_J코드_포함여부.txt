================================================================================
 [문의사항 Q01] 비정량(searchType=4) 출하대상 WHERE 조건 IN ('J', 'B') 중 'J' 포함 여부
================================================================================


--------------------------------------------------------------------------------
 1. 질문 요지 (한 줄)
--------------------------------------------------------------------------------

비정량 출하대상 조회 쿼리의 "타입구분 IN ('J', 'B')" 조건에서 'J'(가공육)가
'비정량'과 다른 카테고리임에도 비정량 출하대상 조회에 함께 포함되고 있습니다.
왜 함께 포함되는지 확인 부탁드립니다.


--------------------------------------------------------------------------------
 2. 발견 경위
--------------------------------------------------------------------------------

- search_production_nonfixed.jsp의 WHERE 조건 분석 과정에서
  정량('W') vs 비정량(IN ('J', 'B')) 차이 확인
- 사용자 확인 결과: B = 비정량(확정), J = 가공육 (비정량과 다른 카테고리)


--------------------------------------------------------------------------------
 3. 기술적 사실 (확정)
--------------------------------------------------------------------------------

[항목 1] 원본 Oracle VIEW에도 동일 IN ('J', 'B') 조건 존재
        근거: app/doc/view/VW_PDA_WID_LIST_NONFIXED:127

[항목 2] 정량(이마트) JSP는 = 'W' 조건만 사용 (가공육 포함 안 함)
        근거: search_shipment.jsp:116

[항목 3] 홈플러스 비정량(searchType=5)은 J/B 조건 없음
        -> BARCODE_TYPE = 'H5' 별개 조건 사용
        근거: app/doc/view/VW_PDA_WID_LIST_NONFIXED_HP:45

[항목 4] 홈플러스 정량(searchType=2)도 J/B 조건 없음
        -> ITEM_TYPE = 'W' (원료육) 조건 사용
        근거: app/doc/view/VW_PDA_WID_HOMEPLUS_LIST:108, 208

[항목 5] IN ('J', 'B') 조건은 이마트 비정량(searchType=4)만의 고유 특성
        근거: 위 1~4 종합


 3.1 searchType별 타입구분 조건 비교표

  ┌─────────────┬─────────────────┬──────────────────────────────────────────────┬─────────────────────────┐
  │ searchType  │ 명칭            │ 타입 조건                                     │ 비고                    │
  ├─────────────┼─────────────────┼──────────────────────────────────────────────┼─────────────────────────┤
  │      0      │ 이마트 정량     │ COALESCE(M1/M2.타입구분) = 'W'                │ 원료육                  │
  │      2      │ 홈플러스 정량   │ EB.ITEM_TYPE = 'W'                            │ 원료육 (VIEW 내부)      │
  │    * 4 *    │ 이마트 비정량   │ COALESCE(M1/M2.타입구분) IN ('J', 'B')        │ * 본 문의 대상 *        │
  │      5      │ 홈플러스 비정량 │ BEB.BARCODE_TYPE = 'H5'                       │ 바코드타입 기반         │
  └─────────────┴─────────────────┴──────────────────────────────────────────────┴─────────────────────────┘

  * 본 문의(Q01)의 scope는 이마트 비정량(searchType=4)에만 한정됨


--------------------------------------------------------------------------------
 4. 확인 요청 사항
--------------------------------------------------------------------------------

 [핵심 질문]

 비정량 진행 시 타입구분 J + B 둘 다 포함하면 됩니까?

  - 즉 COALESCE(M1.타입구분, M2.타입구분) IN ('J', 'B') 조건을
    현 상태 그대로 유지해도 업무상 문제가 없습니까?
  - 아니면 'J'(가공육)를 제외하고 'B'만 사용해야 합니까?
