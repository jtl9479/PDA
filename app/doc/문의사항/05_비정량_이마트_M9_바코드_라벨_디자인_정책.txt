 [문의사항 Q05] 비정량 이마트 M9 바코드 — 기존 정량 M9과 BARCODE_TYPE 코드값 중복
================================================================================


--------------------------------------------------------------------------------
 1. 질문 요지 (한 줄)
--------------------------------------------------------------------------------

기존 BARCODE_TYPE='M9'(정량 이마트 우육 센터납)이 이미 사용 중인데,
신규로 추가하려는 BARCODE_TYPE='M9'(비정량 이마트)와 코드값이 중복됩니다.
이 중복 사용이 의도된 것입니까, 아니면 비정량용으로 별도 BARCODE_TYPE 코드값을
사용해야 합니까?


--------------------------------------------------------------------------------
 2. 발견 경위
--------------------------------------------------------------------------------

- 사용자 요청: 비정량 이마트(searchType=4)에 BARCODE_TYPE='M9' 신규 추가
- 코드 분석 결과: 기존 정량 이마트(searchType=0)에서 이미 BARCODE_TYPE='M9' 사용 중
- 동일한 'M9' 코드값을 정량과 비정량 두 용도로 사용하면
    BARCODE_TYPE만으로는 식별 불가


--------------------------------------------------------------------------------
 3. 기술적 사실 (확정)
--------------------------------------------------------------------------------

[항목 1] 기존 BARCODE_TYPE='M9' 사용 중 (정량 이마트 우육 센터납)
        근거: LabelPrintHelper.java:648 case "M9": 주석 "이마트 우육 센터납"

[항목 2] 정량 M9 BARCODE_TYPE 변환 조건
        근거: Oracle 원본 VW_PDA_WID_LIST L78, L211
        조건: CENTER_SCALE_USE_YN='Y'
              AND BI.ITEM_TYPE='10'
              AND BI.MAJOR_CATEGORY='10' 만족 시 → 'M9'

[항목 3] 신규 비정량 M9 추가 요청
        비정량 이마트(searchType=4)에서 동일 코드값 'M9' 사용

[항목 4] 두 M9의 BARCODE_TYPE 코드값 동일
        모두 'M9'

[항목 5] ERP CO_매출처품목코드매핑.바코드타입에 'M9' 등록 시 식별 모호
        같은 'M9' 등록값으로는 정량/비정량 구분 불가 (다른 조건으로 분기 필요)


--------------------------------------------------------------------------------
 4. 확인 요청 사항
--------------------------------------------------------------------------------

 [핵심 질문]

 기존 BARCODE_TYPE='M9'(정량 이마트 우육 센터납)을 제거하고,
 비정량 이마트 전용 BARCODE_TYPE='M9'으로 재정의하여 진행해도 됩니까?

  - 기존 정량 M9(이마트 우육 센터납)은 더 이상 사용하지 않는 것으로 처리
  - BARCODE_TYPE='M9'은 앞으로 비정량 이마트 전용으로만 운영
