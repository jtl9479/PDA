```java
private void startWeighing(String searchType, String wrongTypeMessage, String emptyListMessage) {
    // 1. searchType 검증
    if (!Common.searchType.equals(searchType)) {
        Toast.makeText(..., wrongTypeMessage, ...);  // "출하를 위해 출하 리스트를 받아주세요."
        vibrator.vibrate(300);
        return;  // 진입 불가
    }

    // 2. DB에서 출하대상 리스트 조회
    ArrayList<Shipments_Info> list = DBHandler.selectqueryAllShipment(this);

    // 3. 리스트 존재 여부 확인
    if (list.size() > 0) {
        // 진입 가능 -> BixolonShipmentActivity로 이동
        Intent i = new Intent(this, BixolonShipmentActivity.class);
        startActivity(i);
    } else {
        // 진입 불가
        Toast.makeText(..., emptyListMessage, ...);  // "출하대상 리스트가 없습니다."
        vibrator.vibrate(300);
    }
}
```

### 2.5 find_work_info() 상세

**파일**: `BixolonShipmentActivity.java:1739-1803`

```java
private String find_work_info(String req, boolean type) {
    String pp_code = "";
    int count = 0;

    // 1. TB_BARCODE_INFO 전체 조회
    ArrayList<Barcodes_Info> list_barcode_info = DBHandler.selectqueryBarcodeInfo(this);

    for (Barcodes_Info bi : list_barcode_info) {
        String bg = bi.getBARCODEGOODS();           // "8801234567890"
        String bg_from = bi.getBARCODEGOODS_FROM(); // "4"
        String bg_to = bi.getBARCODEGOODS_TO();     // "16"

        // 2. 바코드에서 BARCODEGOODS 추출
        // req = "01088012345678900125260113001"
        // substring(4-1, 16) = substring(3, 16) = "8801234567890"
        String temp_bg = req.substring(Integer.parseInt(bg_from) - 1, Integer.parseInt(bg_to));

        // 3. 일치 여부 확인
        if (temp_bg.equals(bg)) {
            // 일치! PACKER_PRODUCT_CODE 반환
            pp_code = bi.getPACKER_PRODUCT_CODE();  // "TEST_PKR_001"
            work_item_barcodegoods = bg;
            count++;
        }
    }

    return pp_code;  // "TEST_PKR_001"
}
```

#### 바코드 추출 계산

```
바코드: 01088012345678900125260113001
인덱스: 0123456789...

BARCODEGOODS_FROM = 4, BARCODEGOODS_TO = 16
substring(4-1, 16) = substring(3, 16)

인덱스 3~15 추출:
  인덱스 3:  '8'
  인덱스 4:  '8'
  인덱스 5:  '0'
  인덱스 6:  '1'
  인덱스 7:  '2'
  인덱스 8:  '3'
  인덱스 9:  '4'
  인덱스 10: '5'
  인덱스 11: '6'
  인덱스 12: '7'
  인덱스 13: '8'
  인덱스 14: '9'
  인덱스 15: '0'

결과: "8801234567890" (13자)
```

| 6 | GI_REQ_DATE 일치 | Common.selectDay = TB_SHIPMENT.GI_REQ_DATE |
