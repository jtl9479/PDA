## 호출 흐름

```
[MainActivity] 이마트 출하대상받기 버튼
    ↓
① search_shipment.jsp (출하대상 조회)
    ↓ 자동
② search_barcode_info.jsp (바코드 정보 조회)
    ↓ 자동
```

## 시나리오 1: 정상 조회

### 절차

```
1. 앱 실행
2. 로그인 (ID/PW 입력)
3. 창고 선택 (Spinner에서 서버 창고 목록 표시 확인)
4. 날짜 선택 (출고 데이터가 있는 날짜)
5. 이마트 출하대상받기 버튼 클릭
6. 로딩 다이얼로그 3단계 확인 (출하대상 → 바코드정보 → 계근정보)
7. 바코드정보 없는 상품 다이얼로그 확인
```

### 확인 항목

| # | 확인 항목 | 예상 결과 | 확인 |
|---|----------|----------|:----:|
| 1 | ① search_shipment.jsp 호출 | 서버 로그에 쿼리 출력 | □ |
| 2 | ① 응답 데이터 | `receiveData`에 30개 컬럼 데이터 | □ |
| 3 | ① TB_SHIPMENT INSERT | `insertqueryShipment` 로그 출력 | □ |
| 4 | ② search_barcode_info.jsp 호출 | `Barcode Code List : WHERE SBI.PPCODE = '...'` | □ |
| 5 | ② 응답 데이터 | `Barcode receiveData`에 25개 컬럼 데이터 | □ |
| 6 | ② TB_BARCODE_INFO INSERT | `insertqueryBarcodeInfo` 로그 출력 | □ |
| 7 | ③ search_goods_wet.jsp 호출 | `Wet GI_D_ID List : WHERE 출고상세SEQ = '...'` | □ |
| 8 | ③ 응답 데이터 | 초회 조회 시 0건 (미계근 상태) | □ |
| 9 | 앱 비정상 종료 | 없음 | □ |

### 로그 확인 명령어

```bash
adb logcat -d -s "ProgressDlgShipSearch" "pDlgBarcodeSearch" "pDlgGoodsWetSearch" "DBHandler" | tail -30
```
