이마트 출하계근이마트 출하 → 계근 → 라벨 → 전송 전체 흐름

정량중량 버림 표시

사전 조건

#항목조건
1서버 가동출하 관리 서버 실행 중
2DB업무 DB 접속 가능
3서버 연결 설정앱의 서버 연결 설정 확인 (정상 주소로 연결)
4테스트 데이터이마트 정량 출고 데이터 준비 완료 (출고수량>0인 품목)
5PDA 기기동일 네트워크(Wi-Fi) 연결 (Honeywell EDA51)
6프린터BIXOLON 프린터 Bluetooth/Socket 페어링 완료

기능 흐름

[로그인 후] 창고 선택 → 날짜 선택 → 이마트 출하대상받기 버튼 클릭
    ↓ (자동) 로딩 진행 후 출하 목록 구성
[계근입력시작] BixolonShipmentActivity 진입 → 센터/BL번호/지점 선택
    ↓
[계근 입력] 이마트 바코드 스캔 또는 수기 중량입력
    ↓ 수입육센터/미트센터 등 소비기한 필요 상품을 "수기" 입력 시
[소비기한 입력] ExpiryEnterActivity 입력창 → 소비기한 입력 후 복귀
    ↓
[라벨 인쇄] 이마트 양식 라벨 자동 출력 (상품명/중량/바코드)
    ↓
[계근 전송] 전송 버튼 → 전송 완료 → 계근완료 표시

■ 정량

시나리오 1 정상 흐름 (출하대상받기 → 바코드 스캔 계근 → 라벨 → 전송)

절차

1. 앱 실행
2. 로그인 (ID/PW 입력)
3. 창고 선택 (Spinner에 창고 목록 표시 확인)
4. 날짜 선택 (이마트 출고 데이터가 있는 날짜)
5. 이마트 출하대상받기 버튼 클릭
6. 로딩 진행 후 출하 목록이 구성되는지 확인
7. 바코드정보 없는 상품 안내 다이얼로그 확인 후 닫기
8. 이마트 계근입력시작 버튼 클릭 → 계근 화면 진입
9. 센터 / BL번호 / 지점 스피너에서 계근 대상 선택
10. 첫 번째 상품 이마트 바코드 스캔
11. 화면에 상품명·계근 중량이 표시되는지 확인 (소수점 둘째 자리 이하 버림 표시)
12. 라벨 자동 인쇄 스위치 ON 상태 확인
13. 계근 완료 시 라벨이 자동 출력되는지 확인
14. 계근 전송 버튼 클릭
15. 전송 완료 후 계근완료 표시로 변경되는지 확인
16. ERP S0205(PDA출고계근현황) 화면에서 전송한 계근 내역이 조회되는지 확인

확인 항목

#확인 항목예상 결과확인
1출하대상받기 버튼 클릭로딩 후 출하 목록이 화면에 구성됨
2바코드정보 없는 상품 안내해당 상품이 있으면 안내 다이얼로그 표시
3계근입력시작계근 화면으로 정상 진입, 센터/BL/지점 선택 가능
4바코드 스캔스캔 시 상품명·중량이 화면에 자동 표시됨
5중량 버림 표시이마트 계근 중량이 소수점 둘째 자리 이하 버림되어 화면에 표시됨 (예: 12.87 → 12.8)
6라벨 자동 출력계근 완료 시 이마트 양식 라벨이 자동 출력됨 (상품명/중량/바코드 육안 확인)
7계근 전송전송 버튼 클릭 시 전송 완료 안내가 표시됨
8계근완료 표시전송 후 해당 상품이 계근완료 상태로 표시됨
9ERP 반영 확인ERP S0205(PDA출고계근현황)에서 전송한 계근 내역(계근바코드·계근순번·계근중량)이 조회됨
10앱 비정상 종료없음

시나리오 2 바코드 스캔 계근 상세 확인

절차

1. 시나리오 1의 출하대상받기 완료 후 상태에서 진행
2. 이마트 계근입력시작 클릭 → 계근 화면 진입
3. 첫 번째 상품 이마트 바코드 스캔
4. 화면의 중량 값 및 상품정보 표시 확인
5. 동일 바코드 재스캔
6. 두 번째 박스 바코드 스캔
7. 전체 박스 계근 완료 후 상태 확인

확인 항목

#확인 항목예상 결과확인
1첫 번째 바코드 스캔상품정보·중량이 화면에 표시됨
2중량 표시반올림된 중량 값이 화면에 표시됨
3계근 수량 표시스캔 후 계근수량 1/N 정상 표시
4동일 바코드 재스캔"이미 스캔한 바코드입니다" 경고 표시 + 진동 (중복 차단)
※ 비정량은 중복 차단하지 않고 동일 바코드 스캔 허용 (08_이마트비정량_출하계근_전체테스트 참조)
5두 번째 바코드 스캔계근수량 2/N 정상 증가
6센터 합계 표시선택 센터의 요청/완료 수량·중량 합계가 실시간 갱신됨
7전체 완료 감지요청 수량 도달 시 완료 안내 다이얼로그 표시
8앱 비정상 종료없음

시나리오 3 수기 중량입력 계근

절차

1. 출하대상받기 완료 후 계근 화면 진입
2. 작업모드 스피너 → "수기"로 변경
3. 상품 선택 후 중량 수동 입력
4. 입력 완료 후 계근 처리 확인
5. 라벨 출력 확인
6. 계근 전송 확인

확인 항목

#확인 항목예상 결과확인
1수기 모드 선택작업모드 "수기" 변경 후 수동 입력 필드 활성화
2중량 수동 입력키패드로 중량값 직접 입력 가능
3중량 반올림 표시수기 입력 중량도 이마트 반올림되어 표시됨
4계근 처리입력 확인 시 계근 처리되고 수량/중량이 반영됨
5라벨 출력이마트 양식 라벨이 출력됨
6계근 전송전송 버튼 클릭 시 전송 완료 안내가 표시됨
7계근완료 표시전송 후 해당 상품이 계근완료 상태로 표시됨
8앱 비정상 종료없음

시나리오 4 수입육 소비기한 수기입력

절차

1. 출하대상받기 완료 후 계근 화면 진입
2. 소비기한 대상 상품 선택 — 수입육센터 납품 또는 미트센터 상품
3. 작업모드 "수기"로 중량 직접 입력 후 확인  (★바코드 스캔이 아니라 "수기 중량입력 확인" 시 소비기한 입력창이 뜸)
4. 소비기한 입력창이 자동으로 뜨는지 확인
5. 소비기한(유통기한) 날짜 입력 → 확인 후 계근 화면 복귀
6. 입력한 소비기한이 계근 데이터/라벨에 반영되는지 확인
※ 바코드 스캔 경로에서는 입력창이 뜨지 않으며, 미트센터/트레이더스 상품에 소비기한 정보가 없으면 "소비기한정보 필수" 안내로 계근이 차단됨

확인 항목

#확인 항목예상 결과확인
1소비기한 입력창 자동 표시수입육센터/미트센터 상품을 수기 중량입력 확인 시 소비기한 입력 화면이 자동으로 뜸 (바코드 스캔 시에는 뜨지 않음)
2소비기한 입력 UI날짜 입력 필드가 정상 표시됨
3날짜 입력허용 형식 입력 가능, 비허용 형식 방어 처리
4확인 후 복귀입력값 전달하여 계근 화면으로 정상 복귀
5라벨 소비기한 출력이마트 양식 라벨에 소비기한이 정상 인쇄됨
6소비기한 정보 누락 시소비기한 정보 없는 상품은 "소비기한정보 필수" 안내로 계근 차단
7계근 전송소비기한 포함하여 전송 완료됨
8앱 비정상 종료없음

시나리오 5 라벨 인쇄 및 재출력

절차

1. 시나리오 1 또는 2 계근 완료 후 라벨 자동 인쇄 확인
2. 메뉴 → 재출력 선택
3. 이미 계근된 항목 선택 후 라벨 재출력
4. 라벨 자동 인쇄 스위치 OFF 후 수동 인쇄 버튼으로 출력

확인 항목

#확인 항목예상 결과확인
1라벨 자동 인쇄자동 인쇄 ON 상태에서 계근 완료 시 자동 출력됨
2이마트 양식이마트 양식 라벨로 출력됨
3라벨 내용 - 상품명상품명이 정상 표시됨 (육안 확인)
4라벨 내용 - 중량반올림된 계근 중량이 정상 표시됨 (육안 확인)
5라벨 내용 - 바코드이마트 바코드가 정상 인쇄됨 (육안 확인)
6라벨 재출력메뉴 재출력 기능이 정상 동작함
7자동 인쇄 OFF자동 인쇄 OFF 시 계근 후 자동 출력되지 않음
8합계 라벨 인쇄합계 버튼 클릭 시 중량 합산 라벨이 출력됨
9앱 비정상 종료없음

시나리오 6 계근 전송 성공 (복수 건 순차 전송)

절차

1. 바코드 스캔으로 복수 건 계근 완료
2. 계근 전송 버튼 클릭
3. 전송 진행 후 완료 안내 확인
4. 계근완료 상태로 변경되는지 확인

확인 항목

#확인 항목예상 결과확인
1계근 전송 실행전송 버튼 클릭 시 전송이 진행됨
2전송 완료 안내전송 성공 안내가 표시됨
3전송 실패 시실패 시 오류 안내가 표시되고 계근완료로 바뀌지 않음
4전송 완료 후 화면계근완료 상태 갱신 및 다음 상품으로 이동
5앱 비정상 종료없음

시나리오 7 데이터 없는 날짜

절차

1. 앱 실행 → 로그인
2. 이마트 출고 데이터가 없는 날짜 선택
3. 이마트 출하대상받기 버튼 클릭

확인 항목

#확인 항목예상 결과확인
1빈 목록 표시출하 목록이 빈 상태로 표시됨
2사용자 안내"데이터가 없습니다" 또는 빈 목록 안내가 표시됨
3앱 비정상 종료없음
