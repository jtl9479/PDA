## 호출 흐름

```
[MainActivity] 롯데 출하대상받기 버튼 (searchType=6)
    ↓
① search_shipment_lotte.jsp (출하대상 조회, 26개 컬럼 0~25)
     - WHERE H.마트사구분 = '6'
     - AND COALESCE(M1.타입구분, M2.타입구분) = 'W'
     - AND D.출고수량 > 0
     - (+창고 선택 시 창고코드 조건 추가)
     - LEFT JOIN SM_수주상세 SD (행 팽창 WARN)
     - Index 24: '' AS WH_AREA (빈값 고정)
     - Index 25: TOP 1 서브쿼리 → LAST_BOX_ORDER (최근 박스순번, 최초 NULL 가능)
    ↓ 자동
② search_barcode_info.jsp (바코드 정보 조회, 정량 공용, 25개 컬럼)
     - WHERE SBI.ppCode = '...' (TB_SHIPMENT의 PACKER_PRODUCT_CODE 기준)
    ↓ 자동
③ search_goods_wet.jsp (계근 내역 조회)
     - WHERE 출고상세SEQ IN (TB_SHIPMENT GI_D_ID 목록)
    ↓
[출하대상 목록 표시] → lotte_TryCount 계산
     - lotte_TryCount = LAST_BOX_ORDER + 1 (최초 NULL → try-catch, 오류22-9)
     - 기존 계근 PACKING_QTY 합산 후 다음 박스순번 확정
    ↓
④ 바코드 스캔 / 수기 중량입력 (+소비기한 창)
     - 계근 성공 시: DBHandler.insertqueryGoodsWetLotte() (로컬DB 저장, 박스순번 기록)
     - lotte_TryCount++ (1~9999 순환, 9999 초과 시 1로 회귀)
    ↓
⑤ 라벨 인쇄 — setPrintingLotte()
     - 롯데 전용 양식 (중량 소수점 2자리, EMARTLOGIS_CODE 업체코드 사용)
    ↓
⑥ 계근전송 — insert_goods_wet.jsp (구로직, 1건씩)
     - SM_출고계근 INSERT (NEXT VALUE FOR SM_DLIVY_WEIGH_SEQ)
     - 전송 성공: "s" 수신 / 실패: "f" 수신
```

## 시나리오 4: 출하대상 행 팽창(중복) 검증

### 절차

```
1. DB에서 SM_수주상세 테이블의 해당 마트사SEQ에 대한 행 수 확인
   (동일 마트사SEQ에 복수 행이 있는지 확인)
2. 앱 실행 → 롯데 출하대상받기 클릭
3. 출하대상 목록 건수를 ERP 발주 건수와 비교
4. 중복 행 발생 여부 확인
```

### 확인 항목

| # | 확인 항목 | 예상 결과 | 확인 |
|---|----------|----------|:----:|
| 1 | SM_수주상세 LEFT JOIN 행 수 | `SELECT COUNT(*) FROM SM_수주상세 WHERE 마트사SEQ = ?` → ERP 기대값과 비교 | □ |
| 2 | 출하대상 목록 건수 | ERP 출고 건수와 동일 (행 팽창 없음 = 정상) | □ |
| 3 | 행 팽창 발생 시 | 동일 GI_D_ID가 복수 행으로 표시됨 → 오류 문서 작성 필요 | □ |
| 4 | STORE_IN_DATE 값 | 납기일자 정상 표시 (datetime 타입이면 오류22-1 해소 필요) | □ |
| 5 | 앱 비정상 종료 | 없음 | □ |

### 검증 쿼리 (MSSQL weberp_dev)

```sql
-- 행 팽창 확인: 동일 마트사SEQ 기준
SELECT D.SEQ, COUNT(*) AS row_cnt
FROM SM_출고상세 D
INNER JOIN SM_출고머리 H ON H.회사코드 = D.회사코드
    AND H.출고사업장 = D.출고사업장
    AND H.출고일자 = D.출고일자
    AND H.출고일련번호 = D.출고일련번호
JOIN SM_마트사발주롯데마트 LE ON D.마트사SEQ = LE.SEQ
LEFT JOIN SM_수주상세 SD ON SD.마트사SEQ = LE.SEQ
WHERE H.마트사구분 = '6'
  AND D.출고일자 = '20260623'   -- 테스트 날짜로 변경
GROUP BY D.SEQ
HAVING COUNT(*) > 1;
```
