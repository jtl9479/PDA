작업자 화면·동작 기준 기능 테스트 · 대상: 생산 계근 · 흐름: 날짜 선택 → 생산계근대상받기 → 계근입력 → 스캔/수기 → 전송 (라벨 없음)

생산 계근생산작업지시 → 계근대상받기 → 계근 → 전송 전체 흐름

생산라벨 출력 없음중량 변환 없음

이마트 출고계근과의 차이

항목이마트 출고생산 계근
대상 데이터출고 (ERP S0201에서 등록)생산작업지시 자재 (ERP P0101에서 등록)
대상 품목마트 납품 상품대분류 2(상품) = 생산 투입 원료만
센터명실제 거래처 상호"하이랜드푸드" 고정 (스피너 항목 1개)
프린터 연결필요 (Bluetooth 페어링)불필요 — 연결 요구 자체가 없음
라벨 출력계근 시 자동 출력없음 (인쇄 스위치 OFF 고정·조작 불가)
수기 중량품목코드관리에서 설정입력값 그대로
소비기한 입력창수입육·미트센터 시 표시표시되지 않음
지점명 표시점포명거래처 상호 (미입력 시 공백 — 정상)

사전 조건

#항목조건
1서버 가동출고 관리 서버 실행 중
2DB업무 DB 접속 가능
3서버 연결 설정앱의 서버 연결 설정 확인 (정상 주소로 연결)
4생산작업지시ERP 생산작업지시(P0101) 등록 완료 — 자재 1건 이상
5품목 마스터대상 자재의 바코드 정보 등록 (상품바코드·바코드상품코드시작/끝·중량시작/끝·소수점)
6박스중량품목코드에 박스중량 필수 등록 (요청 박스수 계산에 사용)
7PDA 기기동일 네트워크(Wi-Fi) 연결 (Honeywell EDA51)
8프린터불필요 — 생산 계근은 라벨을 출력하지 않음
사전 조건 5·6 미충족 시 계근이 시작되지 않습니다. 바코드 정보가 없으면 스캔해도 "바코드 정보(조회결과)가 없습니다" 또는 "패커상품이 존재하지않거나, 바코드가 정확하지 않습니다" 안내가 표시됩니다. 이는 앱 오류가 아니라 ERP 품목 마스터 미등록입니다.

기능 흐름

[ERP] 생산작업지시 등록 (P0101) → 투입 자재 목록 생성
    ↓
[로그인 후] 날짜 선택 → 생산계근대상받기 버튼 클릭
    ↓ (자동) 로딩 진행 후 생산 계근 목록 구성
[생산계근입력시작] 계근 화면 진입 → 센터("하이랜드푸드")/BL/지점 선택
    ↓ 프린터 연결 요구 없음 · 인쇄 스위치 OFF 고정
[계근 입력] 바코드 스캔 또는 수기 중량입력
    ↓ 라벨 출력 단계 없음
[계근 전송] 전송 버튼 → 전송 완료 → 계근완료 표시
    ↓
[재조회] 생산계근대상받기 재실행 시 계근 완료 건은 목록에서 제외
계근 대상 산정 — 요청 박스수는 실소요량 ÷ 박스중량(올림)으로 계산됩니다. 예) 실소요량 16.55kg, 박스중량 18.0kg → 요청 1박스

■ 생산 계근

시나리오 1 정상 흐름 (생산계근대상받기 → 바코드 스캔 계근 → 전송)

절차

1. 앱 실행
2. 로그인 (ID/PW 입력)
3. 날짜 선택 (생산작업지시가 등록된 날짜)
4. 생산계근대상받기 버튼 클릭
5. 로딩 진행 후 생산 계근 목록이 구성되는지 확인
6. 생산계근입력시작 버튼 클릭 → 계근 화면 진입
7. 프린터 연결 요구(블루투스 켜기·프린터 선택)가 없는지 확인
8. 인쇄 스위치가 OFF 상태로 고정되어 조작되지 않는지 확인
9. 첫 번째 자재 바코드 스캔
10. 화면에 상품명·PP코드·계근 중량이 표시되는지 확인
11. 라벨이 출력되지 않는지 확인
12. 계근 전송 버튼 클릭
13. 전송 완료 후 계근완료 표시로 변경되는지 확인
14. ERP P0210(PDA생산계근현황) 화면에서 전송한 계근 내역이 조회되는지 확인

확인 항목

#확인 항목예상 결과확인
1생산계근대상받기 버튼 클릭로딩 후 생산 계근 목록이 화면에 구성됨
2대상 품목 범위생산 투입 원료(상품)만 조회됨 — 원자재·부자재·반제품은 제외
3요청 박스수 표시정수로 표시됨 (소수점 없음)
4계근입력시작계근 화면으로 정상 진입
5프린터 연결 요구 없음블루투스 켜기·프린터 선택 화면이 나타나지 않음
6인쇄 스위치 고정OFF 상태이며 터치해도 변경되지 않음
7바코드 스캔스캔 시 상품명·PP코드·중량이 화면에 자동 표시됨
8라벨 미출력계근해도 라벨이 출력되지 않음
9계근 전송전송 버튼 클릭 시 전송 완료 안내가 표시됨
10계근완료 표시전송 후 해당 자재가 계근완료 상태로 표시됨
11ERP 반영 확인ERP P0210(PDA생산계근현황)에서 전송한 계근 내역(계근바코드·계근순번·계근중량)이 조회됨
12앱 비정상 종료없음

시나리오 2 바코드 스캔 계근 상세 확인

절차

1. 시나리오 1의 대상받기 완료 후 상태에서 진행
2. 생산계근입력시작 클릭 → 계근 화면 진입
3. 첫 번째 자재 바코드 스캔
4. 화면의 중량 값 및 상품정보 표시 확인
5. 동일 바코드 재스캔
6. 두 번째 박스 바코드 스캔
7. 요청 박스수만큼 계근 완료 후 상태 확인

확인 항목

#확인 항목예상 결과확인
1첫 번째 바코드 스캔상품정보·중량이 화면에 표시됨
2계근 수량 표시스캔 후 계근수량 1/N 정상 표시
3동일 바코드 재스캔"이미 스캔한 바코드입니다" 경고 표시 + 진동 (중복 차단)
4두 번째 바코드 스캔계근수량 2/N 정상 증가
5센터 합계 표시요청/완료 수량·중량 합계가 실시간 갱신됨
6전체 완료 감지요청 박스수 도달 시 완료 안내 다이얼로그 표시
7지점명 표시거래처 상호 표시 (미입력 시 공백 — 정상 동작)
8앱 비정상 종료없음

시나리오 3 계근 방식 확인 (정량 / 비정량)

품목 마스터의 비정량 여부 설정에 따라 계근 중량 처리가 달라집니다. 두 경우를 모두 확인합니다.

절차

[A] 비정량 미체크 품목 (정량)
1. ERP 품목코드관리에서 대상 자재의 "비정량 여부" 미체크 확인
2. 생산계근대상받기 → 계근입력시작
3. 바코드 스캔
4. 화면에 표시되는 계근 중량 확인 → 품목의 박스중량 값과 동일한지 확인
5. 박스를 여러 개 계근했을 때 모든 박스 중량이 동일한지 확인

[B] 비정량 체크 품목
6. ERP 품목코드관리에서 대상 자재의 "비정량 여부" 체크
7. 생산계근대상받기 재실행 → 계근입력시작
8. 바코드 스캔
9. 화면에 표시되는 계근 중량이 바코드의 실제 중량과 일치하는지 확인
10. 박스마다 중량이 다르게 기록되는지 확인

확인 항목

#확인 항목예상 결과확인
1[A] 정량 - 계근 중량품목의 박스중량 고정값으로 기록됨
2[A] 정량 - 박스별 중량모든 박스가 동일한 중량으로 기록됨
3[A] 정량 - 제조일자/박스시리얼기록되지 않음 (빈값)
4[B] 비정량 - 계근 중량바코드의 실제 중량이 기록됨
5[B] 비정량 - 박스별 중량박스마다 다른 중량으로 기록됨
6[B] 비정량 - 제조일자바코드에서 추출되어 기록됨
7[B] 비정량 - 소수점소수점 둘째자리까지 표시됨
8앱 비정상 종료없음

시나리오 4 수기 중량입력 계근

절차

1. 대상받기 완료 후 계근 화면 진입
2. 작업모드 스피너 → "수기"로 변경
3. 지점 선택 후 중량 수동 입력 (예: 12.34)
4. 입력 버튼 클릭
5. 화면에 표시되는 중량 확인
6. 계근 전송 확인

확인 항목

#확인 항목예상 결과확인
1수기 모드 선택작업모드 "수기" 변경 후 수동 입력 필드 활성화
2중량 수동 입력키패드로 중량값 직접 입력 가능
3중량 변환 없음입력값이 그대로 표시됨 (이마트와 달리 버림 처리 없음)
4중량 미입력 시"중량을 입력하세요." 안내 표시
5지점 미선택 시"작업 중인 지점이 없습니다." 안내 표시
6소비기한 입력창표시되지 않음 (생산은 대상 아님)
7계근 처리입력 확인 시 계근 처리되고 수량/중량이 반영됨
8라벨 미출력수기 계근에도 라벨이 출력되지 않음
9계근 전송전송 버튼 클릭 시 전송 완료 안내가 표시됨
10앱 비정상 종료없음
