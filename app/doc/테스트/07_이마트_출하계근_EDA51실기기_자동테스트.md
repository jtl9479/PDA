    ↓ (ProgressDlgBarcodeSearch)

    ↓

## 발견 사항 (비고)

1. **데이터없음/서버미연결 UX 동일**: 조회일자에 데이터가 없는 경우(시나리오 8)와 서버 미연결(시나리오 9) 모두 동일하게 빈 "바코드정보 없는 상품목록" 다이얼로그가 표시되며, 서버 미연결에 대한 명시적 "연결 실패" 안내는 확인되지 않았다. → **오류 30** 문서화 완료(현상 절에 통합 서술).
2. **응답 파싱 시 ArrayIndexOutOfBoundsException 상시 발생**: 빈 응답·오류 응답 처리 시 파싱 과정에서 항상 ArrayIndexOutOfBoundsException이 발생하나 catch로 방어되어 앱 크래시는 없음. 2회차(20260715 빈 응답)에서 동일 재현. → **오류 30** 문서화 완료.
3. **(2회차 신규) 주석·문서의 "반올림" 표기가 실제 동작(버림)과 불일치**: 이마트 수기 중량은 `Math.floor(weight*10)/10.0`로 **버림**이나, javadoc(`BixolonShipmentActivity.java:621`, `:1556`)은 "반올림"으로 기재. **원본(`ShipmentActivity.java:324-330`)과 코드 동작은 100% 동일**하므로 코드 수정 대상이 아니며 표기만 정정 필요. → **오류 31** 문서화 완료.
4. **(2회차 신규) 서버 미기동인데 "ERP 설정 미비"로 안내**: 앱 최초 실행 시점에 **서버(weberp_dev)가 기동되지 않은 상태**여서 창고 조회가 실패했는데, 화면에는 "ERP 창고관리(C0114)에서 PDA여부를 설정하세요"가 표시되고 로그인이 차단되었다. 서버 기동 후 재시작하니 동일 조건에서 정상 조회됨(W301). 즉 실제 원인은 **연결 실패**인데 앱은 **ERP 설정 미비**라는 다른 원인을 단정한다. 통신 실패와 데이터 0건이 모두 빈 문자열로 수렴하여 구분되지 않는 것이 근본 원인(`LoginActivity.java:96-105` 조회 메서드, `:127-134` 0건 분기). → **오류 29** 문서화 완료.
