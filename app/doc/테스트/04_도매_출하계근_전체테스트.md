## 호출 흐름

```
[MainActivity] 도매업체출하대상받기 버튼 (searchType=3)
    ↓
① search_shipment_wholesale.jsp (출하대상 조회, 24개 컬럼)
    WHERE H.마트사구분='' AND D.출고수량>0 AND I.원료육여부='1'
    AND D.회사코드=? AND D.출고일자=?  [AND D.창고코드=? 창고 선택 시]
    ORDER BY D.SEQ ASC
    ↓ 자동
② search_barcode_info.jsp (바코드 정보 조회, 정량 공용)
    WHERE SBI.PPCODE = '...' AND SBI.ppCode != ''
    ↓ 자동
③ search_goods_wet.jsp (계근 내역 조회)
    WHERE 출고상세SEQ IN (...)
    ↓
[완료] 바코드정보 없는 상품 다이얼로그 표시
    ↓
[계근입력시작] BixolonShipmentActivity (searchType=3 도매 분기)
    ↓
④ 바코드 스캔 / 수기 중량입력 → 계근 등록
    ↓
⑤ 라벨 인쇄 (도매 양식, LabelPrintHelper)
    ↓
⑥ 계근전송 → insert_goods_wet_new.jsp ("##" 배치 전송 → SM_출고계근 INSERT)
```

## 시나리오 1: 정상 E2E (출하대상받기 → 바코드 스캔 계근 → 라벨 인쇄 → 계근전송)

### 절차

```
1. 앱 실행 → 로그인
2. 창고 선택 (Spinner에서 서버 창고 목록 표시 확인)
3. 날짜 선택 (도매 출고 데이터가 있는 날짜)
4. 도매업체출하대상받기 버튼 클릭 (searchType=3)
5. 로딩 다이얼로그 3단계 확인 (출하대상 → 바코드정보 → 계근정보)
6. 바코드정보 없는 상품 다이얼로그 확인
7. 도매업체 계근입력시작 버튼 클릭
8. 품목 목록에서 계근할 상품 선택 (CLIENTNAME/CENTERNAME = 거래처명 동일값 확인)
9. 바코드 스캔 → 중량 확인 → 계근 등록
10. 라벨 자동 인쇄 확인 (도매 양식)
11. 모든 박스 계근 완료 → 계근전송 버튼 클릭
12. 서버 전송 완료 확인 (응답 "s")
```

## 시나리오 2: 원료육여부='1' 식별 조회 검증 (도매 식별 조건 확인)

### 절차

```
1. 앱 실행 → 로그인 → 날짜 선택 (도매 출고 데이터가 있는 날짜)
2. 도매업체출하대상받기 버튼 클릭
3. 서버 로그에서 실행된 WHERE 조건 확인
4. 조회 결과 품목들의 원료육여부 값이 모두 '1'인지 ERP DB에서 교차 확인
5. 타입구분/바코드타입 필터가 없음을 로그로 확인
```

### 확인 항목

| # | 확인 항목 | 예상 결과 | 확인 |
|---|----------|----------|:----:|
| 1 | WHERE I.원료육여부='1' 적용 | 서버 로그 쿼리에 `I.원료육여부 = '1'` 포함 | □ |
| 2 | WHERE H.마트사구분='' 적용 | 서버 로그 쿼리에 `H.마트사구분 = ''` 포함 (빈문자열, 타 마트사와 구분) | □ |
| 3 | 타입구분/바코드타입 필터 없음 | 쿼리에 COALESCE(M1.타입구분, M2.타입구분) 조건 없음 | □ |
| 4 | 거래처MASTER 2차 필터 없음 | JOIN ON에 B.마트사구분 = '' 조건 없음 (이마트·홈플러스와 차이) | □ |
| 5 | 조회 결과 품목 | 원료육여부='1' 인 품목만 목록에 표시됨 | □ |
| 6 | 앱 비정상 종료 | 없음 | □ |

### 로그 확인 명령어

```bash
adb logcat -d -s "ProgressDlgShipSearch" | grep -i "search_shipment"
```
