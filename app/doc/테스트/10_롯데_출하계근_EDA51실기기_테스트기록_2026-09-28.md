```bash
adb shell svc power stayon true                 # 화면 꺼짐 방지
adb shell input tap <x> <y>                     # 터치
adb exec-out screencap -p > s.png               # 화면 캡처
```

## 5. 발견 결함

### 🔴 오류37 — 롯데 첫 계근 시 박스순번 0 적재

```
BixolonShipmentActivity: result's Count : 3
BixolonShipmentActivity: e : java.lang.NumberFormatException: For input string: ""
DBHandler: insertqueryGoodsWetLotte -> ... ,'0')
TB_GOODS_WET: GI_D_ID=270 WEIGHT=6.0 BOX_ORDER=0        ← 1이어야 함
```

`LAST_BOX_ORDER` 가 빈 문자열 → `Integer.parseInt("")` 예외 → 채번 블록 통째로 스킵 → `lotte_TryCount` 가 `0` 유지.

**앱 코드는 원본과 동일**하므로 JSP 전환 시 NULL 방어가 누락된 건이다.
조치안(`COALESCE(..., 0)`) 포함 상세는 **`오류/37_롯데_LAST_BOX_ORDER_NULL_parseInt예외_박스순번_0적재[롯데_EDA51_실기기테스트].md`** 참조.

### ⚠️ 라벨 출력 — 프린터 미연결

```
BixolonSocketPrinter: at android.bluetooth.BluetoothSocket.write(BluetoothSocket.java:556)
                      at LabelPrintHelper.setPrintingLotte(LabelPrintHelper.java:1479)
```

커맨드 생성까지는 정상(`print Barcode : 2026080506008809790000`, `print Weight : 000600`, 바코드타입 `L0`).
**결함 아님** — 프린터 전원/페어링 필요.
