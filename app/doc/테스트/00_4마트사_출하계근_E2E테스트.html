1. 시나리오 1 완료 후 (TB_SHIPMENT에 데이터 있는 상태)
2. 다시 롯데 출하대상받기 클릭
3. 서버 데이터와 로컬 동기화 확인

확인 항목

#확인 항목예상 결과확인
1기존 데이터 삭제 후 재삽입deletequeryShipment 로그 후 insertqueryShipment 로그
2서버 없는 건 삭제PDA에만 있고 서버에 없는 GI_D_ID 삭제
3서버 추가 건 삽입서버에 새로 추가된 GI_D_ID 삽입
4lotte_TryCount 재계산재조회 후 LAST_BOX_ORDER+1 기반으로 재계산
5기존 계근 이어가기재조회 후 기존 PACKING_QTY 합산하여 다음 박스순번 정상

로그 확인 명령어

adb logcat -d -s "ProgressDlgShipSearch" "DBHandler" | grep -E "delete|insert|lotte_TryCount"
