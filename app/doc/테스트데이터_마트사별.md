## 1. 테스트 바코드 목록 (중요!)

### 1.1 바코드 구조

```
[3자리 prefix][13자리 상품코드][4자리 중량][6자리 날짜][3자리 박스번호] = 29자리
```

**바코드 추출 설정:**
- `BARCODEGOODS_FROM = 4`
- `BARCODEGOODS_TO = 16`
- `substring(3, 16)` → **13자리 추출**
