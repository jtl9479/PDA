---

## 개요

| 항목 | 내용 |
|------|------|
| 작성일 | 2026-01-13 |
| 용도 | BixolonShipmentActivity 라벨 출력 테스트 |
| 대상 마트 | 이마트, 홈플러스, 롯데마트, 도매업체 |

## 1. searchType별 마트사

| searchType | 마트사 | VIEW | 라벨 출력 메서드 |
|:----------:|--------|------|-----------------|
| 0 | 이마트 | VW_PDA_WID_LIST | setPrinting() |
| 2 | 홈플러스 | VW_PDA_WID_HOMEPLUS_LIST | setHomeplusPrinting() |
| 3 | 도매업체 | VW_PDA_WID_WHOLESALE_LIST | (바코드 타입 NA) |
| 4 | 이마트 비정량 | VW_PDA_WID_LIST_NONFIXED | setPrinting() |
| 5 | 홈플러스 비정량 | VW_PDA_WID_LIST_NONFIXED_HP | setHomeplusPrinting() |
| 6 | 롯데마트 | VW_PDA_WID_LIST_LOTTE | setPrintingLotte() |

## 8. 바코드 타입별 라벨 출력 분기

### 8.1 이마트 바코드 타입 (setPrinting)

| 바코드 타입 | 설명 | 라벨 형식 |
|------------|------|----------|
| M0 | 기본 | 표준 라벨 |
| M1 | 타입1 | 확장 라벨 |
| M3 | 타입3 | 수입식별번호 포함 |
| M4 | 타입4 | 원산지명 포함 |
| M8 | 수입식별번호 | 별도 필드 |
| M9 | 납품일자 | 날짜 필드 추가 |
| E0~E3 | 이마트 확장 | 센터별 분기 |
| P0 | 기본 바코드 | 단순 형식 |

| 바코드 타입 | 설명 |
|------------|------|
| H0 | 홈플러스 기본 |
| HW | 홈플러스 원료육 |

### 8.3 롯데 바코드 타입 (setPrintingLotte)

| 바코드 타입 | 설명 |
|------------|------|
| L0 | 롯데 기본 |
| LW | 롯데 원료육 |

## 9. 테스트 시나리오

### 9.1 이마트 라벨 출력 테스트

1. **준비**
   - searchType = "0" 설정
   - 테스트 데이터 1~4 중 선택
   - 프린터 연결 확인

2. **1단계: 상품 바코드 스캔**
   - `PKR_TEST_001` 에 해당하는 바코드 스캔
   - 또는 edit_barcode에 직접 입력

3. **2단계: BL 바코드 스캔**
   - `BL2026011301` 스캔
   - 작업 대상 확정

4. **3단계: 중량 입력**
   - ITEM_TYPE=W: 바코드에서 자동 추출
   - ITEM_TYPE=S: 저울 또는 수동 입력
   - ITEM_TYPE=J: PACKWEIGHT 자동 사용

5. **4단계: 라벨 출력 확인**
   - BARCODE_TYPE에 따른 라벨 형식 확인
   - 출력 내용 검증

### 9.2 홈플러스 라벨 출력 테스트

1. searchType = "2" 설정
2. 홈플러스 테스트 데이터 사용
3. setHomeplusPrinting() 호출 확인

### 9.3 롯데마트 라벨 출력 테스트

1. searchType = "6" 설정
2. 롯데 테스트 데이터 사용
3. LAST_BOX_ORDER 순번 증가 확인
4. 소수점 2자리 중량 확인
