# 이마트 물류코드 기본값 '0000000' 적용 (JSP 2종)

**작성일**: 2026-10-12
**목적**: 이마트·이마트 비정량 출하대상의 EMARTLOGIS_CODE 를 원본 뷰와 같이 값이 없으면 '0000000' 으로 내린다 (오류/42)

## 1. 현재 구조

### search_shipment.jsp / search_production_nonfixed.jsp 60줄

```java
+ ", COALESCE(M1.물류코드, M2.물류코드) AS EMARTLOGIS_CODE"
```

- 매핑 물류코드가 NULL·'' 이면 '' 전송 (원본 Oracle 뷰는 '0000000')

### 문제점

- M0 라벨 `si.getEMARTLOGIS_CODE().substring(0, 6)` 예외 → 라벨 미출력
- 미트센터 분기(`'0000000'` 비교) 원본과 다름

## 2. 변경 구조

### 데이터 흐름

```
[매핑 물류코드 M1 → M2]
    ↓ NULL 또는 ''
['0000000']  ← 원본 DECODE(EO.EMARTLOGIS_CODE, NULL, '0000000', ...)
    ↓
[출하대상 index 23 EMARTLOGIS_CODE]
```

## 4. 수정 상세

**변경 전:**

```java
+ ", COALESCE(M1.물류코드, M2.물류코드) AS EMARTLOGIS_CODE"
```

**변경 후:**

```java
+ ", ISNULL(NULLIF(COALESCE(M1.물류코드, M2.물류코드), ''), '0000000') AS EMARTLOGIS_CODE"   // 원본: DECODE(EO.EMARTLOGIS_CODE,NULL,'0000000',...) (오류/42)
```

**검증**: 물류코드 있는 품목은 값 그대로, 빈 값 품목은 '0000000' — 행 수 변화 없음 (SELECT 컬럼만 변경)
