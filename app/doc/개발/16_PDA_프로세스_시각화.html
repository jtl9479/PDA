PDA 프로세스 시각화 (이마트 출하)

1. 전체 프로세스 흐름

앱 시작
▼
LoginActivity
앱 창고 목록 서버 조회 (search_warehouse.jsp)
앱 ID/PW 입력 → 로그인 (manager_login.jsp)
앱 창고 선택 (Spinner) → Common.selectWarehouseCode 저장
▼ 로그인 성공
MainActivity
날짜 선택 / 출하대상받기 / 계근입력시작
▼ 출하대상받기 클릭
STEP 1 출하대상 다운로드
JSP search_shipment.jsp
DB SM_출고상세 조회 → 앱 TB_SHIPMENT 저장
▼ 자동
STEP 2 바코드 규칙 다운로드
JSP search_barcode_info.jsp
DB CO_품목코드 조회 → 앱 TB_BARCODE_INFO 저장
▼ 자동
STEP 3 기존 계근 데이터 동기화
JSP search_goods_wet.jsp
DB SM_출고계근 조회 → 앱 TB_GOODS_WET 저장 (SAVE_TYPE="Y")
▼ 다운로드 완료
BixolonShipmentActivity (계근 화면)
바코드 스캔 → 중량 추출 → 라벨 인쇄 → 서버 전송

2. 계근 프로세스 (BixolonShipmentActivity)

바코드 스캔
예: 002000100567260310B002
▼
상품 매칭 (find_work_info)
TB_BARCODE_INFO에서 BARCODEGOODS 비교
barcode.substring(FROM-1, TO) == BARCODEGOODS ?
▼ 매칭 성공
ITEM_TYPE별 중량 추출 (setBarcodeMsg)
추출 항목방법예시
중량substring(WEIGHT_FROM-1, TO) / 10^ZEROPOINT00567 → 5.67 KG
제조일substring(MAKINGDATE_FROM-1, TO)260310
박스시리얼substring(BOXSERIAL_FROM-1, TO)B002
▼
계근 데이터 생성 (wet_data_insert)
필드출처
GI_D_IDTB_SHIPMENT
WEIGHT바코드 추출
WEIGHT_UNITTB_BARCODE_INFO (BASEUNIT)
MAKINGDATE, BOXSERIAL바코드 추출
BOX_CNTPACKING_QTY + 1
SAVE_TYPE"F" (미전송)
→ TB_GOODS_WET (로컬 DB) INSERT
→ PACKING_QTY += 1 → UI: "10 / 1"
▼
라벨 인쇄 (LabelPrintHelper)
M0 라벨: 센터명, 배송처명, 상품명, 바코드, 중량, 납품일자, 업체코드/명
→ Bixolon 블루투스 프린터 출력 (SLCS B1 + LD 명령)
▼ GI_REQ_PKG 만큼 반복
GI_REQ_PKG == PACKING_QTY ? → 전송 가능

3. 서버 전송 프로세스

전송 버튼 클릭
▼
TB_GOODS_WET에서 SAVE_TYPE="F" 조회
(미전송 계근 데이터)
▼ 건별 루프
패킷 구성 (:: 구분, 15개 필드)
GI_D_ID :: WEIGHT :: WEIGHT_UNIT :: PACKER_PRODUCT_CODE :: BARCODE :: PACKER_CLIENT_CODE :: MAKINGDATE :: BOXSERIAL :: BOX_CNT :: REG_ID :: ITEM_CODE :: BRAND_CODE :: CLIENT_TYPE :: BOX_ORDER :: COMPANY_CODE
▼
JSP insert_goods_wet.jsp
INSERT INTO SM_출고계근 (...)
응답: "s" (성공) / "f" (실패)
▼ 성공 시
전송 완료 처리
TB_GOODS_WET UPDATE: SAVE_TYPE = "Y"
SAVE_CNT += 1
▼ SAVE_CNT == GI_REQ_PKG (전체 완료)
JSP update_shipment.jsp
계근완료 통보
UPDATE W_GOODS_ID SET CHECK_YN='N'
WHERE GI_D_ID=? AND ITEM_CODE=? AND BRAND_CODE=?
