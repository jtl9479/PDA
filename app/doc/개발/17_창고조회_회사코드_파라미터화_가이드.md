# 창고조회 회사코드 파라미터화 가이드

**작성일**: 2026-03-31
**목적**: search_warehouse.jsp의 하드코딩 회사코드를 앱에서 파라미터로 전달하도록 변경

---

## 1. 현재 구조 (하드코딩)

### search_warehouse.jsp

```sql
String quertystring = "SELECT 회사코드 AS COMPANY_CODE"
    + ", 창고코드 AS WAREHOUSE_CODE"
    + ", 창고명 AS WAREHOUSE_NAME"
    + " FROM CO_창고관리"
    + " WHERE 회사코드 = '20'";
```

- `WHERE 회사코드 = '20'` 하드코딩
- `request.getParameter("data")` 미사용

### LoginActivity.java (WarehouseSearchTask)

```java
return HttpHelper.getInstance().sendDataDb("", "inno",
    "search_warehouse", Common.URL_SEARCH_WAREHOUSE);
```

- data 파라미터에 빈 문자열 전달

### 문제점

- 회사코드 변경 시 JSP 직접 수정 및 서버 재배포 필요
- 다른 JSP(search_shipment.jsp 등)는 `data` 파라미터로 WHERE 조건을 받는 패턴인데 search_warehouse.jsp만 예외

---

## 2. 변경 구조 (파라미터 전달)

### 데이터 흐름

```
[LoginActivity] WarehouseSearchTask
    ↓ data = " WHERE 회사코드 = '20'"
[HttpHelper] sendDataDb(data, "inno", ...)
    ↓ POST data 파라미터
[search_warehouse.jsp] request.getParameter("data")
    ↓ 쿼리에 WHERE 조건 적용
[서버] CO_창고관리 테이블 조회
    ↓ 응답
[LoginActivity] 파싱 → Spinner 구성
```

## 4. 수정 상세

### 4.1 search_warehouse.jsp (외부 Tomcat)

**경로**: `D:\PDA\apache-tomcat-8.5.29\apache-tomcat-8.5.29\webapps\ROOT\inno\search_warehouse.jsp`

**변경 전:**

```jsp
Statement stmt = conn.createStatement();
String quertystring = "SELECT 회사코드 AS COMPANY_CODE"
    + ", 창고코드 AS WAREHOUSE_CODE"
    + ", 창고명 AS WAREHOUSE_NAME"
    + " FROM CO_창고관리"

```

**변경 후:**

```jsp
String qry_where = request.getParameter("data");
System.out.println("##search_warehouse data :" + qry_where);

Statement stmt = conn.createStatement();
String quertystring = "SELECT 회사코드 AS COMPANY_CODE"
```
