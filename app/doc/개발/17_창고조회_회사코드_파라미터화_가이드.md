# 창고조회 회사코드 파라미터화 가이드

**작성일**: 2026-03-31
**목적**: search_warehouse.jsp의 하드코딩 회사코드를 앱에서 파라미터로 전달하도록 변경

---

## 1. 현재 구조 (하드코딩)

### search_warehouse.jsp

```sql
String quertystring = "SELECT 회사코드 AS COMPANY_CODE"
    + ", 창고코드 AS WAREHOUSE_CODE"
    + ", 창고명 AS WAREHOUSE_NAME"
    + " FROM CO_창고관리"
    + " WHERE 회사코드 = '20'";
```

- `WHERE 회사코드 = '20'` 하드코딩
- `request.getParameter("data")` 미사용

### LoginActivity.java (WarehouseSearchTask)

```java
return HttpHelper.getInstance().sendDataDb("", "inno",
    "search_warehouse", Common.URL_SEARCH_WAREHOUSE);
```

- data 파라미터에 빈 문자열 전달

### 문제점

- 회사코드 변경 시 JSP 직접 수정 및 서버 재배포 필요
- 다른 JSP(search_shipment.jsp 등)는 `data` 파라미터로 WHERE 조건을 받는 패턴인데 search_warehouse.jsp만 예외

---

## 2. 변경 구조 (파라미터 전달)

### 데이터 흐름

```
[LoginActivity] WarehouseSearchTask
    ↓ data = " WHERE 회사코드 = '20'"
[HttpHelper] sendDataDb(data, "inno", ...)
    ↓ POST data 파라미터
[search_warehouse.jsp] request.getParameter("data")
    ↓ 쿼리에 WHERE 조건 적용
[서버] CO_창고관리 테이블 조회
    ↓ 응답
[LoginActivity] 파싱 → Spinner 구성
```

## 4. 수정 상세

### 4.1 search_warehouse.jsp (외부 Tomcat)

**경로**: `D:\PDA\apache-tomcat-8.5.29\apache-tomcat-8.5.29\webapps\ROOT\inno\search_warehouse.jsp`

**변경 전:**

```jsp

    + " FROM CO_창고관리"
```

```jsp
String qry_where = request.getParameter("data");
```

### 4.2 LoginActivity.java (WarehouseSearchTask)

**경로**: `app/src/main/java/.../LoginActivity.java`

**변경 전:**

```java
return HttpHelper.getInstance().sendDataDb("", "inno",
    "search_warehouse", Common.URL_SEARCH_WAREHOUSE);
```

```java
String data = " WHERE 회사코드 = '" + Common.selectCompanyCode + "'";

    "search_warehouse", Common.URL_SEARCH_WAREHOUSE);
```

**검증**: 로그에서 data 값 확인

## 5. 사이드이펙트

### 없음

- search_warehouse.jsp는 창고 목록 조회 전용이며 다른 JSP에서 호출하지 않음
- LoginActivity의 WarehouseSearchTask만 호출하므로 영향 범위가 제한적
- `Common.selectCompanyCode`는 기존 `"20"` 하드코딩 유지이므로 전달되는 값 변화 없음

## 6. 데이터 저장 구조

### 변수 매핑

| 변수 | 타입 | 용도 | 예시 |
|------|------|------|------|
| `Common.selectCompanyCode` | String | 회사코드 (WHERE 조건) | "20" |
| `Common.warehouseNames` | ArrayList\<String\> | 창고명 목록 (Spinner) | ["삼일냉장", "SWC", ...] |
| `Common.warehouseCodes` | ArrayList\<String\> | 창고코드 목록 (쿼리 조건) | ["IN10273", "IN60464", ...] |
| `Common.selectWarehouse` | String | 선택된 창고명 | "삼일냉장" |
| `Common.selectWarehouseCode` | String | 선택된 창고코드 | "IN10273" |

### 파라미터 매핑

```
[LoginActivity]
    data = " WHERE 회사코드 = '20'"
        ↓ HttpHelper.sendDataDb(data, ...)
[search_warehouse.jsp]
    qry_where = request.getParameter("data")  →  " WHERE 회사코드 = '20'"
        ↓ 쿼리 조합
    quertystring = "SELECT ... FROM CO_창고관리" + qry_where
```
