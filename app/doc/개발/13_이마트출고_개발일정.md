## 1. 이마트 출고 E2E 흐름

```
로그인 ──→ 출하대상 다운로드 ──→ 바코드 다운로드 ──→ 계근 입력 ──→ 서버 전송 ──→ 출하 확인 ──→ 라벨 인쇄
  │              │                    │                │              │              │            │
  ▼              ▼                    ▼                ▼              ▼              ▼            ▼
manager_    search_shipment_    search_barcode_    로컬 SQLite    insert_goods_    update_     LabelPrint
login.jsp   ono.jsp             info.jsp           TB_GOODS_WET   wet.jsp         shipment    Helper
                │                    │                               │             .jsp        (로컬)
                ▼                    ▼                               ▼
        VW_PDA_WID_LIST_ONO    S_BARCODE_INFO               W_GOODS_WET
        (MSSQL VIEW 신규)      +B_ITEM+B_SUPPLIER_ITEM       →SM_출고LOT
```
