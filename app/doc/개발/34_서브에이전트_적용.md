# 서브 에이전트 적용

**작성일**: 2026-04-09
**목적**: 기능13 문서에 정의된 서브 에이전트 8개를 `.claude/agents/`에 구현 및 적용

---

## AI 제약 조건

- 문서에 명시된 step만 진행하고, 다음 step은 지시를 기다린다
- step 완료 후 체크리스트 + 진행 현황을 반드시 업데이트한다
- 문서에 없는 개선/리팩토링을 임의로 수행하지 않는다

---

## 1. 현재 구조

### 서브 에이전트 없음

현재 `.claude/agents/` 디렉토리 미존재. 모든 작업(문서 생성, 검증, 커밋, 일정)을 메인 에이전트가 수동 수행.

### 문제점

- 일정 문서 완료 작업 반영 누락 (사용자 지적 반복)
- 커밋 후 일정 반영 누락
- 문서 템플릿 준수 여부 수동 확인
- 코드 수정 후 정합성 체크 수동 진행

---

## 2. 변경 구조

### 데이터 흐름

```
[변경 전]
메인 에이전트가 모든 작업 수동 수행
    → 문서 생성, 검증, 커밋, 일정 반영 전부 직접 처리
    → 누락 빈번

[변경 후]
메인 에이전트 = 코드 수정 (사용자 지시)
서브 에이전트 = 보조 작업 자동화
    → ② 오류 문서, ③ 개발 가이드, ④ 기능/소스분석 (문서 생성)
    → ⑤ 코드 검증, ⑥ 원본 비교 (검증)
    → ⑦ 테스트 (테스트)
    → ⑧ 문서 정합성 (문서 검증)
    → ① 일정+커밋 (마무리)
```
