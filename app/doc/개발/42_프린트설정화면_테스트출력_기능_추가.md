# 프린트설정화면 테스트출력 기능 추가

**작성일**: 2026-04-27
**목적**: SettingActivity(프린트 설정 화면)에 "테스트 출력" 버튼을 추가하여, 출하대상받기 진입 전 설정 화면에서 바로 프린터 연결 상태를 확인하고 테스트 라벨 1장을 출력할 수 있도록 한다.

---

## AI 제약 조건

- 기존 WHERE 조건, 로직을 임의로 제거/추가/변경하지 않는다
- 문서에 명시된 step만 진행하고, 다음 step은 지시를 기다린다
- step 완료 후 체크리스트 + 진행 현황을 반드시 업데이트한다
- 문서에 없는 개선/리팩토링을 임의로 수행하지 않는다
- 기존 기능과 100% 동일하게 동작해야 한다

#### 4.2.5 showPrinterSelectDialog() 메서드 추가

**추가 위치**: `onClick()` 메서드 아래

```java
/**
 * 페어링된 블루투스 장치 목록을 다이얼로그로 표시하여 프린터 선택
 * - 선택된 장치의 MAC 주소를 Common.printer_address 및 SharedPreferences에 저장
 * - 저장 후 ProgressDlgPrintConnect 실행하여 연결 시도
 */
private void showPrinterSelectDialog() {
    Set<BluetoothDevice> pairedDevices = mBluetoothAdapter.getBondedDevices();

    if (pairedDevices == null || pairedDevices.size() == 0) {
        Toast.makeText(this, "페어링된 블루투스 장치가 없습니다.", Toast.LENGTH_SHORT).show();
        return;
    }

    final BluetoothDevice[] deviceArray = pairedDevices.toArray(new BluetoothDevice[0]);
    String[] deviceNames = new String[deviceArray.length];

    for (int i = 0; i < deviceArray.length; i++) {
        deviceNames[i] = deviceArray[i].getName() + "\n" + deviceArray[i].getAddress();
    }

    new AlertDialog.Builder(SettingActivity.this, R.style.AppCompatDialogStyle)
            .setTitle("프린터 선택")
            .setItems(deviceNames, new DialogInterface.OnClickListener() {
                @Override
                public void onClick(DialogInterface dialog, int which) {
                    BluetoothDevice selectedDevice = deviceArray[which];
                    String address = selectedDevice.getAddress();
                    Log.d(TAG, "선택된 프린터: " + selectedDevice.getName() + " - " + address);

                    // 선택한 프린터 주소 저장
                    Common.printer_address = address;
                    editor.putString("printer_address", Common.printer_address);
                    editor.commit();

                    // 연결 시도
                    new ProgressDlgPrintConnect(SettingActivity.this).execute();
                }
            })
            .setNegativeButton("취소", null)
            .show();
}
```

#### 4.2.6 ProgressDlgPrintConnect inner class 추가

**추가 위치**: `showPrinterSelectDialog()` 아래

```java
/**
 * 블루투스 프린터 연결 AsyncTask
 * - Common.printer_address에 저장된 주소로 BixolonSocketPrinter 연결 시도
 * - 연결 결과는 mBixolonHandler가 수신 (STATE_CONNECTED → printTestLabel 호출)
 */
class ProgressDlgPrintConnect extends AsyncTask<Integer, String, Integer> {
    private android.content.Context mContext;

    public ProgressDlgPrintConnect(android.content.Context context) {
        mContext = context;
    }

    @Override
    protected void onPreExecute() {
        cDialog = new ProgressDialog(mContext);
        cDialog.setProgressStyle(ProgressDialog.STYLE_SPINNER);
        cDialog.setTitle("프린터 연결중...");
        cDialog.setMessage("잠시만 기다려 주세요..");
        cDialog.setCancelable(false);
        cDialog.show();
        super.onPreExecute();
    }

    @Override
    protected Integer doInBackground(Integer... params) {
        try {
            BluetoothDevice device = mBluetoothAdapter.getRemoteDevice(Common.printer_address);
            Log.d(TAG, "연결 시도 주소: " + Common.printer_address);
            mBixolonPrinter.connect(device);
        } catch (Exception e) {
            Log.e(TAG, "ProgressDlgPrintConnect error: " + e.toString());
        }
        return 0;
    }

    @Override
    protected void onPostExecute(Integer result) {
    }
}
```

#### 4.2.7 mBixolonHandler 추가

**추가 위치**: `ProgressDlgPrintConnect` 아래

```java
/**
 * 빅솔론 프린터 상태 변경 Handler
 * - STATE_CONNECTED: 연결 성공 → printTestLabel() 호출
 * - STATE_NONE (연결 실패 시): 다이얼로그 닫기 + Toast
 */
private final Handler mBixolonHandler = new Handler() {
    @Override
    public void handleMessage(Message msg) {
        switch (msg.what) {
            case BixolonSocketPrinter.MESSAGE_STATE_CHANGE:
                int newState = msg.arg1;
                Log.d(TAG, "Bixolon state -> " + newState);

                switch (newState) {
                    case BixolonSocketPrinter.STATE_CONNECTED:
                        // 연결 성공 → 다이얼로그 닫기 + 테스트 라벨 출력
                        if (cDialog != null && cDialog.isShowing()) {
                            cDialog.dismiss();
                        }
                        Toast.makeText(getApplicationContext(),
                                "프린터 연결 성공. 테스트 출력 중...", Toast.LENGTH_SHORT).show();
                        if (mBixolonPrinter != null) {
                            mBixolonPrinter.printTestLabel();
                        }
                        break;

                    case BixolonSocketPrinter.STATE_NONE:
                        // 연결 실패 → 다이얼로그 닫기 + 실패 Toast
                        if (cDialog != null && cDialog.isShowing()) {
                            cDialog.dismiss();
                        }
                        Toast.makeText(getApplicationContext(),
                                "프린터 연결 실패", Toast.LENGTH_SHORT).show();
                        break;
                }
                break;

            case BixolonSocketPrinter.MESSAGE_TOAST:
                Toast.makeText(getApplicationContext(),
                        (String) msg.obj, Toast.LENGTH_SHORT).show();
                break;

            case BixolonSocketPrinter.MESSAGE_PRINT_COMPLETE:
                Log.d(TAG, "테스트 출력 완료");
                break;
        }
    }
};
```

## 5. 사이드이펙트

### 5.1 Common.printer_address 변경 가능성

```java
// showPrinterSelectDialog() 내부
Common.printer_address = address;
```

- `showPrinterSelectDialog()`에서 프린터를 새로 선택하면 `Common.printer_address`와 `spfBluetooth.printer_address`가 갱신됨
- 이후 출하대상받기(`BixolonShipmentActivity`) 진입 시 해당 주소로 자동 연결 → **정상 동작, 의도된 사이드이펙트**

### 5.2 ProgressDlgPrintConnect 중복 실행 방지

- 테스트 출력 버튼을 연속으로 누르면 AsyncTask가 중복 실행될 수 있음
- `cDialog`가 표시 중일 때 버튼을 다시 누르면 새 AsyncTask가 추가로 실행됨
- 대응 방안: `btn_test_print.setEnabled(false)` → 연결 완료/실패 후 `setEnabled(true)` 처리 (Step 2에서 구현)

### 5.3 onDestroy에서 disconnect() 호출

- `SettingActivity`가 종료될 때 `mBixolonPrinter.disconnect()`가 호출됨
- 테스트 출력 성공 후 설정 화면을 닫으면 연결이 끊어짐 → **정상 동작**
- `BixolonShipmentActivity`는 자체 `mBixolonPrinter` 인스턴스를 생성하므로 영향 없음

### 5.4 BixolonShipmentActivity와 mBixolonPrinter 인스턴스 독립

- `SettingActivity`의 `mBixolonPrinter`와 `BixolonShipmentActivity`의 `mBixolonPrinter`는 별개 인스턴스
- SharedPreferences `printer_address`만 공유하며 블루투스 소켓은 독립적으로 동작
- 영향 없음

```
3. "테스트 출력" 버튼 클릭
4. 페어링된 블루투스 장치 목록 다이얼로그 확인
5. 빅솔론 프린터 선택
6. "프린터 연결중..." 스피너 다이얼로그 표시 확인
7. 연결 완료 → "프린터 연결 성공. 테스트 출력 중..." Toast 확인
8. 프린터에서 테스트 라벨(preview.bmp 이미지) 출력 확인
9. SettingActivity 종료
```

### 시나리오 2: 저장된 프린터 주소 있음 — 자동 연결 후 테스트 출력

```
1. Common.printer_address에 유효한 MAC 주소가 저장된 상태
2. SettingActivity 진입
3. "테스트 출력" 버튼 클릭
4. 다이얼로그 없이 바로 "프린터 연결중..." 스피너 표시 확인
5. 연결 완료 → Toast + 테스트 라벨 출력 확인
```

### 시나리오 3: 블루투스 OFF 상태

```
1. 디바이스 블루투스 비활성화
2. SettingActivity 진입
3. "테스트 출력" 버튼 클릭
4. "블루투스를 켜주세요." Toast 표시 확인
5. 다이얼로그 미표시 확인
```

### 시나리오 4: 연결 실패

```
1. 프린터 전원 OFF 상태 또는 범위 밖
2. SettingActivity 진입 → 테스트 출력 버튼 클릭
3. "프린터 연결중..." 스피너 표시
4. 연결 타임아웃 후 "프린터 연결 실패" Toast 확인
5. 스피너 다이얼로그 닫힘 확인
```

### 시나리오 5: 기존 기능 회귀 확인

```
1. SettingActivity 진입
2. ON 버튼 클릭 → btn_on green, btn_off gray 확인
3. OFF 버튼 클릭 → btn_off green, btn_on gray 확인
4. imageView 7회 클릭 → 계근내역 삭제 다이얼로그 표시 확인
5. SettingActivity 종료 후 설정 저장 확인
```

## 10. 예상 문제점 및 해결 방안

| # | 문제점 | 원인 | 해결 방안 |
|---|--------|------|----------|
| 1 | 테스트 출력 버튼 연속 클릭 시 AsyncTask 중복 실행 | `btn_test_print` 클릭 후 연결 완료 전 재클릭 가능 | `btn_test_print.setEnabled(false)` 처리 후, 연결 성공/실패 시 `setEnabled(true)` 복원 |
| 2 | SettingActivity 종료 후 mBixolonHandler 콜백 수신 | AsyncTask doInBackground 수행 중 화면 종료 | `onDestroy`에서 `mBixolonPrinter.disconnect()` 호출하여 연결 취소. Handler는 Activity 인스턴스가 GC되면 참조 없어짐 |
| 3 | `preview.bmp` 파일 없음 | assets 폴더에 파일 미포함 | `BixolonSocketPrinter.printTestLabel()`에서 IOException 처리 → Toast "테스트 라벨 출력 오류" 표시 |
| 4 | 페어링 장치 없음 | 블루투스 페어링 미완료 | `showPrinterSelectDialog()`에서 size==0 체크 → Toast "페어링된 블루투스 장치가 없습니다." |
| 5 | mBixolonHandler STATE_NONE 오탐 | 연결 시작 시 disconnect() 호출로 인한 STATE_NONE 발생 | BixolonShipmentActivity처럼 mPreviousBixolonState 추적 필요 시 추가 구현 (현재는 단순 구현으로 시작) |
