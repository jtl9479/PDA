### 저장 기준

- **최초 출력 값만 저장**한다. 재출력(`mode.reprint`)은 저장하지 않는다 (출력 당시 유형 유지 목적)

## 4. 수정 상세

### 4.1 JSP 패킷 방어

```java
<%!
// 패킷 idx 값 (없으면 '', 컬럼 길이 초과 시 자름) — 구버전 앱(15필드)·split 뒤쪽 빈 값 대응
static String pkt(String[] s, int idx, int max) {
    if (s.length <= idx || s[idx] == null) return "";
    String v = s[idx];
    return v.length() > max ? v.substring(0, max) : v;
}
%>
```

- `String.split("::")` 는 뒤쪽 빈 값을 버리므로 인덱스 존재 여부로 판단

### 4.2 앱 UPDATE 대상 행

- `GI_D_ID = ? AND GI_L_ID = ? AND BOX_CNT = ? AND SAVE_TYPE = 'F'` — 방금 INSERT 한 행 (BOX_CNT = 계근수량+1)
