## 2. 변경 구조

### 데이터 흐름

```
[합계 버튼 클릭]
    ↓ 계근 0건 → "합산할 항목이 없습니다." (변경 없음)
[파렛트당 박스 수 입력 창] (숫자, 기본값 36)
    ↓ 출력          ↓ 취소 → 인쇄 안 함
[printSumLabel(파렛트당 박스 수)]
    ├── 파렛트 내 순번 k = i % 박스수, 파렛트 번호 = i / 박스수 + 1
    ├── 좌표: 기존 식에 i 대신 k
    ├── k가 36건 경계 & 파렛트 미종료 → 중량만 있는 이어지는 라벨 인쇄 (총 중량 없음, 합계 유지)
    └── 파렛트 끝 또는 마지막 건 → "파렛트번호번 총 중량 : XX.X" 인쇄, 합계 초기화
```

### 출력 예

| 계근 건수 | 박스 수 | 출력 |
|:-:|:-:|------|
| 50 | 36 (기본) | 1번 36건 / 2번 14건 — **현재와 동일** |
| 50 | 20 | 1번 20건 / 2번 20건 / 3번 10건 |
| 50 | 40 | [1번 36건(총 중량 없음) + 1번 4건 총 중량] / 2번 10건 |

**변경 후 (printSumLabel 루프 핵심):**

```java
for (int i = 0; i < list_gi_info.size(); i++) {
    int pallet_no = i / pallet_box_cnt + 1;     // 파렛트 번호
    int k = i % pallet_box_cnt;                 // 파렛트 내 순번
    p_hight = 10 + (k / 6 * 50) - (k / 36 * 300);
    p_weight = 95 * (k % 6);
    ...
    if ((k + 1) == pallet_box_cnt || (i + 1) == list_gi_info.size()) {
        // 총 중량 (기존 반올림 로직 동일) "pallet_no번 총 중량 : XX.X" → 인쇄 → 버퍼·weight_sum 초기화
    } else if ((k + 1) % 36 == 0) {
        // 라벨 1장 가득 참(파렛트 진행 중) → 총 중량 없이 인쇄 → 버퍼만 초기화(weight_sum 유지)
    }
}
```

**검증**: 박스 수 36 입력 시 기존 식과 번호·좌표·장 구분이 같음
- 36건 경계: `(k + 1) == 36` ⇔ `(i + 1) % 36 == 0`, 번호 `i / 36 + 1` = `(i + 1) / 36`
- 마지막 미만 건: 번호 `i / 36 + 1` = `((i + 1) / 36) + 1`
- 좌표: `k = i % 36` 이므로 `k / 6 * 50` = 기존 `(i / 6 * 50) - (i / 36 * 300)`

## 9. 테스트 시나리오

### 시나리오 1: 파렛트 단위 합산

```
1. 출하 1건에 계근 5건
2. 계근 내역 → 합계 → 박스 수 2 → 출력
```
