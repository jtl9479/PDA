## 원인

### 문제 1: TB_BARCODE_INFO INSERT에서 3개 컬럼 누락

#### 코드 위치
- `DBHandler.java` : insertqueryBarcodeInfo() 918~988줄

#### 현재 문제 코드
```java
// DBHandler.java:924~970 - INSERT 컬럼 목록 (22개)
+ DBInfo.STATUS + ", "
+ DBInfo.REG_ID + ", "
// ★ REG_DATE 없음
// ★ REG_TIME 없음
+ DBInfo.SHELF_LIFE
// ★ MEMO 없음
```

#### CREATE TABLE에는 정의됨
```java
// DBHandler.java:699~731 - CREATE TABLE (25개 데이터 컬럼)
+ DBInfo.REG_DATE + " TEXT, "      // 정의됨
+ DBInfo.REG_TIME + " TEXT, "      // 정의됨
+ DBInfo.MEMO + " TEXT, "          // 정의됨
```

#### 파싱에서는 set 함
```java
// ProgressDlgBarcodeSearch.java:129~131
bi.setREG_DATE(temp[21]);    // set하지만 DB 미저장
bi.setREG_TIME(temp[22]);    // set하지만 DB 미저장
bi.setMEMO(temp[23]);        // set하지만 DB 미저장
```

- `BixolonShipmentActivity.java` : wet_data_insert() 1612~1628줄

```java
// BixolonShipmentActivity.java:1612~1628
Goodswets_Info gi = new Goodswets_Info();
```

```java
// DBHandler.java:1402
+ Common.nullCheck(gi.getBOX_ORDER(), "") + "','"
// ★ getBOX_ORDER()는 빈값("") 반환
```

## 영향 범위

| 문제 | 영향 파일 | 실제 동작 영향 |
|------|----------|:------------:|
| REG_DATE/REG_TIME/MEMO 누락 | TB_BARCODE_INFO | **없음** (해당 값 조회하는 코드 없음) |
| BOX_ORDER 빈값 | TB_GOODS_WET | **없음** (이마트 JSP에서 미사용) |
| CLIENT_TYPE NULL | TB_GOODS_WET | **없음** (이마트 JSP에서 미사용) |
