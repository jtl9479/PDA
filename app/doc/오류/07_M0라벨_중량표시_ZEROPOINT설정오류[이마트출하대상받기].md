# M0 라벨 중량 표시 — ZEROPOINT 설정 오류

## 발견일
2026-04-03

## 현상
- M0 라벨 인쇄 시 중량이 `9800.0 KG`으로 표시
- 원본 라벨은 `9.6KG` (소수점 1자리, kg 단위)
- **중량이 g 단위 정수로 표시되어 실사용 불가**

## 원래부터 있던 버그인가?

**NO — 테스트 데이터의 CO_품목코드.소수점(ZEROPOINT) 값이 0으로 설정되어 발생. 원본에서는 적절한 ZEROPOINT 값이 입력되어 있었음.**

## 원인

### 문제 1 (주요): ZEROPOINT = 0 설정

#### 코드 위치
- `BixolonShipmentActivity.java` : 1387~1391행

#### 현재 코드
```java
item_pow = Math.pow(10, Integer.parseInt(work_item_bi_info.getZEROPOINT()));
item_weight_double = Double.parseDouble(item_weight) / item_pow;
```

#### 발생 시나리오

| ZEROPOINT | item_pow | 바코드 중량 `009800` | 계산 결과 | 표시 |
|:---------:|:--------:|:-------------------:|:---------:|------|
| 0 | 10^0 = 1 | 9800 / 1 | 9800.0 | `9800.0 KG` |
| 1 | 10^1 = 10 | 9800 / 10 | 980.0 | `980.0 KG` |
| 2 | 10^2 = 100 | 9800 / 100 | 98.0 | `98.0 KG` |
| **3** | **10^3 = 1000** | **9800 / 1000** | **9.8** | **`9.8 KG`** |

**ZEROPOINT = 3으로 설정해야 원본과 동일한 kg 단위 표시.**

## 수정 방안

### CO_품목코드 테이블 데이터 수정

```sql
UPDATE CO_품목코드
SET 소수점 = 3
WHERE 회사코드 = '20' AND 품목코드 = '1110100694'
```
