# 합산 라벨 파렛트 출력 최신 원본 불일치

## 발견일
2026-10-22

## 에러 발생 시나리오

```
1. 최신 원본(D:\PDA\PDA-INNO_20261021\PDA-INNO\PDA-INNO, 2026-10-21 스냅샷)과 현재 소스 비교
2. 최신 원본 커밋 56b101d (2026-08-28) "'합산' 출력 시 파렛트당 박스수 입력받아 출력하기" 확인
3. 현재 소스의 같은 기능(개발/79, 수정 리스트 C2)과 입력 창·라벨 출력 내용 대조
4. 입력 창 동작과 라벨에 찍히는 문구·위치·크기가 최신 원본과 다름
```

---

## 현상
- 계근 내역 팝업 [합산] → 파렛트당 박스 수 입력 → 합산 라벨 출력 기능이 최신 원본과 현재 소스에 **각각 따로 구현**되어 있음
- 파렛트 끊는 단위, 라벨 1장 36건(6열×6행), 개별 중량 행·열 배치(프린터 전환 보정 32/95 제외), 총 중량 반올림은 같음
- **라벨 하단 문구가 다름**: 최신 원본은 `(1/2)` 페이지 번호 + `N박스 총 중량 :` + 중량(크게), 현재는 `N번 총 중량 : XX.X`만 출력
- **입력 창 동작이 다름**: 최신 원본은 잘못 입력하면 입력 창을 다시 띄우고 바깥 터치·뒤로가기로 닫히지 않음, 현재는 토스트 후 창이 닫힘

### 입력 창 비교

| 항목 | 최신 원본 (`palletCountDialog`) | 현재 (`WetDetailDialog` detail_btn_sum) |
|------|------|------|
| 제목 | 파렛트당 박스 수 | 합산 라벨 |
| 메시지 | 한 파렛트에 쌓는 박스 수를 입력하세요. | 파렛트당 박스 수를 입력하세요. |
| 기본값 | 36 (전체 선택) | 36 (전체 선택) — 같음 |
| 취소 가능 | `setCancelable(false)` | 기본(true) — 바깥 터치·뒤로가기로 닫힘 |
| 0·공백 입력 | 토스트 "파렛트당 박스 수를 정확히 입력하세요." + 진동 1초 + **입력 창 다시 표시** | 토스트 "파렛트당 박스 수를 입력하세요." + 진동 1초, 창 닫힘 |
| 취소 버튼 | 닫기 (인쇄 없음) | 닫기 (인쇄 없음) — 같음 |

### 라벨 출력 비교

| 항목 | 최신 원본 (`printSumLabel`, Woosim) | 현재 (`SumLabel.print`, Bixolon) |
|------|------|------|
| 개별 중량 | (100×열, 10+50×행) 40 | (95×열, 10+50×행) 32 — 오류/38·개발/71 프린터 전환 보정 |
| 장 넘김 | 36건 가득 참 / 파렛트 끝 / 마지막 건 | 같음 |
| 페이지 번호 | 장마다 `(현재장/파렛트 장 수)` (20, 380) 30 | **없음** |
| 파렛트 끝 문구 | `{파렛트 박스 수}박스 총 중량 : ` (95, 380) 37 | `{파렛트 번호}번 총 중량 : XX.X` (100, 350) 60 |
| 파렛트 끝 중량 | `XX.X` (360, 355) 75 | 위 문구에 포함 |
| 넘침 처리 | 없음 | 폭 576 초과 시 x 왼쪽 이동(최소 10) → 크기 축소(최소 40) (개발/79 Step 3) |

## 원래부터 있던 버그인가?

**NO - 구 원본(`D:\PDA\PDA-INNO(원본)`)에는 이 기능이 없어 개발/79(2026-10-12)에서 자체 구현함. 최신 원본은 2026-08-28 커밋으로 같은 기능을 다르게 구현해 두었고, 이번 최신 원본 수령으로 차이가 확인됨.**

```java
// 3971 printSumLabel(int BOX_PER_PALLET) : 합산 라벨 출력
```

## 상세 흐름

1. **합산 버튼 클릭** (계근 1건 이상)
   - 최신 원본·현재 모두 박스 수 입력 창 표시 (기본 36)
   - 결과: 동일

2. **잘못된 값 입력** (0·공백)
   - **최신 원본**: 토스트 + 진동 → 입력 창 다시 표시 (기본 36)
   - **현재**: 토스트 + 진동 → 창 닫힘, 합산 버튼을 다시 눌러야 함

3. **라벨 출력** (박스 수 N)
   - **최신 원본**: 장마다 `(현재장/장 수)`, 파렛트 마지막 장에 `박스 수 + 총 중량` 문구와 중량(75)
   - **현재**: 파렛트 마지막 장에 `파렛트 번호 + 총 중량` 한 줄(60), 페이지 번호 없음

> 수정 시 주의사항
> - 개별 중량 크기 32·열 간격 95는 프린터 전환 보정(오류/38, 개발/71)이므로 유지
> - 중량(75)은 Korail 폰트 기준 1000kg 이상에서 폭 576 초과(예: 1234.5 → 593) → **넘칠 때만 x=360 유지, 크기 2씩 축소**(사용자 결정 2026-10-22). 999.9kg 이하는 최신 원본 좌표·크기 그대로
> - 개발/79 Step 3의 x 왼쪽 이동은 제거 (`N박스 총 중량 :` 문구와 겹치므로)
