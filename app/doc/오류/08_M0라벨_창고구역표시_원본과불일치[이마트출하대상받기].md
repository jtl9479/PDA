## 원인

### 확인 필요: M0 라벨에 WH_AREA 출력 코드 존재 여부

원본 ShipmentActivity.java에서 M0 라벨 인쇄 시 WH_AREA를 출력하는지, 현재 BixolonShipmentActivity/LabelPrintHelper에서 추가된 것인지 비교 필요.

## 영향 범위
- M0 라벨 인쇄 레이아웃
- 다른 바코드 타입(M1, E0~E3 등) 라벨에도 동일 문제 가능

## 수정 방안

원본 비교 후 결정:
- 원본에도 WH_AREA 출력이 있었으면 → 테스트 데이터 문제 (WH_AREA 빈값으로 설정)
