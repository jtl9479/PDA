## 3. 테스트 바코드 (M0)

### 바코드 구조

```
상품코드6자리 + 중량6자리 + 회사코드 + 수입식별번호12자리
```

### 테스트 바코드 목록

> ZEROPOINT = 2 (중량값 ÷ 100 = kg)

|  #  | 바코드 (30자리)                       |  중량값   | ÷100 | 표시      | 용도       |
| :-: | -------------------------------- | :----: | ---: | ------- | -------- |
|  1  | `111010000980610933202604020001` | 000980 |  9.8 | 9.8 KG  | 기본 테스트   |
|  2  | `111010001230610933202604020001` | 001230 | 12.3 | 12.3 KG | 중량 다른 박스 |
|  3  | `111010001550610933202604020001` | 001550 | 15.5 | 15.5 KG | 중량 다른 박스 |
|  4  | `111010002010610933202604020001` | 002010 | 20.1 | 20.1 KG | 20kg 초과  |
|  5  | `111010001100610933202604020001` | 001100 | 11.0 | 11.0 KG | 정수 중량    |

### 테스트 시나리오별 스캔 순서

#### 시나리오 A: 중량 다른 바코드 순차 스캔

| 회차 | 바코드 | 예상 결과 | 화면 표시 | 확인 |
|:----:|--------|----------|----------|:----:|
| 1 | #1 (9.8kg) | 정상 계근 | 계근수량 1/60, 중량 9.8kg | □ |
| 2 | #2 (12.3kg) | 정상 계근 | 계근수량 2/60, 중량 12.3kg | □ |
| 3 | #3 (15.5kg) | 정상 계근 | 계근수량 3/60, 중량 15.5kg | □ |

#### 시나리오 B: 동일 바코드 반복 스캔 (중복 체크 확인)

| 회차 | 바코드 | 예상 결과 | 화면 표시 | 확인 |
|:----:|--------|----------|----------|:----:|
| 1 | #1 (9.8kg) | 정상 계근 | 계근수량 1/60, 중량 9.8kg | □ |
| 2 | #1 (9.8kg) | **차단** | Toast "이미 스캔한 바코드입니다", 진동 | □ |
| 3 | #2 (12.3kg) | 정상 계근 | 계근수량 2/60, 중량 12.3kg | □ |

#### 시나리오 C: 계근수량 완료 후 동일 바코드 스캔 (01번 오류문서 관련)

> GI_REQ_PKG = 60 기준, 테스트 시 GI_REQ_PKG를 3으로 축소 권장

| 회차 | 바코드 | 예상 결과 | 화면 표시 | 확인 |
|:----:|--------|----------|----------|:----:|
| 1 | #1 (9.8kg) | 정상 계근 | 계근수량 1/3 | □ |
| 2 | #2 (12.3kg) | 정상 계근 | 계근수량 2/3 | □ |
| 3 | #3 (15.5kg) | 정상 계근 + 완료 | 계근수량 3/3, 완료 다이얼로그 | □ |
| 4 | #1 (9.8kg) | **차단** | 계근 완료 상태 → 라벨 재출력 안됨 | □ |

> 시나리오 C 4회차: 01번 오류문서(계근완료후 동일바코드 라벨재출력 버그)에 해당. 원본에서 미수정 상태이므로 **라벨이 재출력될 수 있음**.

### 바코드 구조 분해

```
111010 000980 610933 202604020001
└─1~6─┘└7~12─┘└13~18┘└──19~30───┘
상품코드  중량   회사코드  수입식별번호
```

| 위치 | 고정/변동 | 값 | 의미 |
|:----:|:--------:|------|------|
| 1~6 | 고정 | `111010` | 상품코드 (BARCODEGOODS 매칭) |
| 7~12 | **변동** | `000980` 등 | 중량 (ZEROPOINT=2, ÷100 = kg) |
| 13~18 | 고정 | `610933` | 회사코드 |
| 19~30 | 고정 | `202604020001` | 수입식별번호 |

### 바코드 매칭 로직

```
스캔 바코드: 111010000980610933202604020001
    ↓ substring(BARCODEGOODS_FROM-1, BARCODEGOODS_TO) = substring(0, 6)
추출값: 111010
    ↓ equals(TB_BARCODE_INFO.BARCODEGOODS)
비교: 111010 == 111010 → 매칭 성공
    ↓ substring(WEIGHT_FROM-1, WEIGHT_TO) = substring(6, 12)
중량 추출: 000980 → 980 ÷ 100 (ZEROPOINT=2) = 9.8 KG
```
