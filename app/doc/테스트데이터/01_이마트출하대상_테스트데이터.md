## 3. 테스트 바코드 (M0)

### 바코드 구조

```
상품코드6자리 + 중량6자리 + 회사코드 + 수입식별번호12자리
```

### 테스트 바코드

```
111010012300610933202604020001
```

| 위치 | 값 | 의미 |
|:----:|------|------|
| 1~6 | `111010` | 상품코드 (BARCODEGOODS 매칭) |
| 7~12 | `012300` | 중량 12300g (ZEROPOINT=0) |
| 13~18 | `610933` | 회사코드 |
| 19~30 | `202604020001` | 수입식별번호 |

### 바코드 매칭 로직

```
스캔 바코드: 111010012300610933202604020001
    ↓ substring(BARCODEGOODS_FROM-1, BARCODEGOODS_TO) = substring(0, 6)
추출값: 111010
    ↓ equals(TB_BARCODE_INFO.BARCODEGOODS)
비교: 111010 == 111010 → 매칭 성공
    ↓ substring(WEIGHT_FROM-1, WEIGHT_TO) = substring(6, 12)
중량 추출: 012300 → 12300g (ZEROPOINT=0)
```
