| Index | 컬럼 | 비정량 값 | 이마트 값 | 차이 이유 |

| 17 | PACKER_PRODUCT_CODE | 품목코드 (예: 1110200350) | `I.PPCODE` (예: PC001) | 패커 없으므로 자사 품목코드 사용 |

| 21 | BARCODEGOODS | 품목코드 (예: 1110200350) | `I.상품바코드` (예: 111010) | 패커 없으므로 자사 품목코드 사용 |

### WHERE 조건 차이

| 조건 | 비정량 | 이마트 | 비고 |
|------|--------|--------|------|
| 타입구분 | `IN ('J', 'B')` | `= 'W'` | 제품/비정량 vs 원료육 |
| 바코드타입 | `= 'M8'` | 조건 없음 | 비정량 M8 전용 조건 추가 |

## 3. 테스트 바코드 (M8)

### 바코드 구조

비정량 M8 바코드는 품목코드 기반이다. 바코드 위치는 CO_품목코드의 바코드상품코드시작/끝, 중량시작/끝 설정에 따라 결정된다.

```
품목코드10자리 + 중량6자리 + 수입식별번호12자리
```

### 테스트 바코드 목록

> ZEROPOINT = 0 (중량값 그대로 = g 또는 kg, 품목 설정에 따라)

| # | 바코드 (28자리) | 중량값 | 표시 | 용도 |
|:-:|---------------|:------:|------|------|
| 1 | `1110200350009800202604070001` | 009800 | 9800 g (또는 9.8 kg) | 기본 테스트 |
| 2 | `1110200350012300202604070001` | 012300 | 12300 g (또는 12.3 kg) | 중량 다른 박스 |
| 3 | `1110200350015500202604070001` | 015500 | 15500 g (또는 15.5 kg) | 중량 다른 박스 |

### 바코드 구조 분해

```
1110200350 009800 202604070001
└──1~10──┘└11~16┘└───17~28───┘
 품목코드   중량    수입식별번호
```

| 위치 | 고정/변동 | 값 | 의미 |
|:----:|:--------:|------|------|
| 1~10 | 고정 | `1110200350` | 품목코드 (BARCODEGOODS 매칭) |
| 11~16 | **변동** | `009800` 등 | 중량 (ZEROPOINT=0) |
| 17~28 | 고정 | `202604070001` | 수입식별번호 |

### 바코드 매칭 로직

```
스캔 바코드: 1110200350009800202604070001
    ↓ substring(BARCODEGOODS_FROM-1, BARCODEGOODS_TO) = substring(0, 10)
추출값: 1110200350
    ↓ equals(TB_BARCODE_INFO.BARCODEGOODS)
비교: 1110200350 == 1110200350 → 매칭 성공
    ↓ substring(WEIGHT_FROM-1, WEIGHT_TO) = substring(10, 16)
중량 추출: 009800 → 9800 (ZEROPOINT=0)
```

## 4. 데이터 출처

### ERP 입력 조건

비정량 데이터가 search_production_nonfixed.jsp에서 조회되려면 다음 조건을 만족해야 한다.

| # | 테이블 | 조건 | 설명 |
|---|--------|------|------|
| 1 | SM_출고머리 | 마트사구분 = '7' | 비정량 마트사 구분 |
| 2 | SM_출고상세 | 출고수량 > 0 | 출고 수량 존재 |
| 3 | CO_매출처품목코드매핑 | 타입구분 IN ('J', 'B') | 제품/비정량 타입 |
| 4 | CO_매출처품목코드매핑 | 바코드타입 = 'M8' | M8 바코드 전용 |
| 5 | SM_출고LOT | 출고상세SEQ 연결 | LOT 데이터 존재 |
| 6 | CO_품목코드 | 품목코드 존재 | 품목 마스터 등록 |
| 7 | SM_마트사발주이마트 | SEQ 연결 | 마트사 발주 데이터 존재 |
| 8 | CO_거래처MASTER | 마트사구분 = '7' | 거래처 마트사 구분 일치 |

## 5. 이마트 테스트 데이터와의 비교

| 항목 | 이마트 (searchType=0) | 비정량 (searchType=4) |
|------|---------------------|---------------------|
| JSP | search_shipment.jsp | search_production_nonfixed.jsp |
| 컬럼 수 | 31개 | 31개 (전환 후 동일) |
| PACKER_CODE | 패커코드 (예: 00001) | '0000' 고정 |
| PACKER_PRODUCT_CODE | PPCODE (예: PC001) | 품목코드 (예: 1110200350) |
